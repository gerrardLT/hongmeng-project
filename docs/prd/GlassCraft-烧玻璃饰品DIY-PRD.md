# 烧玻璃饰品DIY（GlassCraft）产品需求文档


## 1 执行摘要

我们正在为追求个性化体验的年轻消费者构建一款烧玻璃饰品DIY预约与体验管理应用GlassCraft，解决用户想体验烧玻璃但找不到合适工作室、预约流程繁琐的问题。提供线上预约、款式选择、作品预览、到店体验记录功能，结合服务卡片提醒和作品分享，成为连接用户与烧玻璃工作室的桥梁。预期上架后30天内获得300+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
22-35岁的年轻消费者，包括情侣、闺蜜、手工爱好者，喜欢尝试新鲜体验，愿意为小众手工活动付费，使用华为鸿蒙设备。

### 2.2 问题是什么
烧玻璃DIY是近年来兴起的小众手工体验，但用户面临以下问题：
- 找不到附近的工作室（信息分散在小红书/大众点评）
- 不了解项目内容和价格（需要逐个咨询）
- 预约流程繁琐（电话/微信沟通）
- 无法提前了解制作流程和难度
- 作品完成后缺少记录和分享方式

### 2.3 为什么这是痛点
- **信息不对称**：烧玻璃工作室多为小而美的独立店铺，曝光度低
- **决策成本高**：不知道做什么款式、需要多长时间、难度如何
- **预约体验差**：传统预约方式效率低，容易撞期
- **社交需求**：完成的作品想记录和分享，但缺少专门的平台

### 2.4 证据
- 烧玻璃DIY在小红书是热门话题，相关笔记超10万+
- 大众点评上烧玻璃工作室数量快速增长
- 客单价200-500元，用户付费意愿强
- 情侣/闺蜜约会场景需求旺盛

## 5 解决方案概述

### 5.1 产品定位
GlassCraft是一款烧玻璃饰品DIY预约与体验管理应用，提供工作室发现、项目浏览、在线预约、作品记录分享功能。

### 5.2 核心用户流程

5.2.1 发现工作室流程
打开App → 查看附近工作室 → 浏览工作室详情 → 查看项目 → 选择项目

5.2.2 预约流程
选择项目 → 选择日期时间 → 填写人数 → 确认预约 → 支付定金 → 收到确认

5.2.3 到店体验流程
到达工作室 → 出示预约码 → 开始体验 → 完成作品 → 拍照记录

5.2.4 作品记录流程
上传作品照片 → 添加制作心得 → 生成分享卡片 → 分享到社交平台

### 5.3 功能模块

5.3.1 工作室发现模块
- 地图模式：
  - 显示附近烧玻璃工作室
  - 按距离排序
  - 点击查看详情
- 列表模式：
  - 工作室列表
  - 评分/价格/距离筛选
- 工作室详情：
  - 环境照片
  - 项目列表
  - 价格区间
  - 用户评价
  - 营业时间
  - 联系方式

5.3.2 项目浏览模块
- 项目分类：
  - 戒指
  - 耳环
  - 吊坠
  - 摆件
  - 其他
- 项目详情：
  - 成品照片
  - 制作时长
  - 难度等级
  - 价格
  - 适合人群
  - 制作流程说明
- 款式选择：
  - 颜色选择
  - 形状选择
  - 效果预览

5.3.3 预约管理模块
- 预约流程：
  - 选择日期（日历展示可约时间）
  - 选择时间段
  - 填写人数
  - 选择项目
  - 填写备注
  - 支付定金
- 预约管理：
  - 查看预约列表
  - 取消预约
  - 修改预约
  - 预约提醒
- 预约码：
  - 到店出示二维码
  - 工作室扫码核销

5.3.4 作品记录模块
- 上传作品：
  - 拍照上传
  - 添加制作心得
  - 记录制作日期
  - 关联工作室和项目
- 作品相册：
  - 按时间展示
  - 作品集展示
  - 生成分享卡片
- 分享功能：
  - 生成精美分享图
  - 分享到微信/小红书
  - 保存到相册

5.3.5 社区模块（V1.1）
- 作品展示墙
- 点赞评论
- 经验分享

5.3.6 服务卡片
- 预约提醒卡片：显示 upcoming 预约信息
- 作品展示卡片：展示最近作品
- 探索推荐卡片：推荐附近工作室

### 5.4 鸿蒙特性利用清单

| 鸿蒙能力 | 应用场景 | 优先级 |
|----------|---------|--------|
| 服务卡片 | 预约提醒、作品展示 | P1 |
| 华为账号 Account Kit | 一键登录 | P2 |
| 意图框架 | 到达工作室附近提醒出示预约码 | P2 |

### 5.5 页面结构
- 首页：附近工作室推荐、热门项目
- 探索：地图/列表模式浏览工作室
- 预约：预约管理、历史记录
- 作品：个人作品相册、分享
- 我的：个人资料、设置

### 5.6 数据模型

5.6.1 工作室表（Studio）
- studioId：String，唯一标识
- name：String，工作室名称
- address：String，地址
- location：Object，经纬度
- phone：String，电话
- photos：Array<String>，环境照片
- rating：Number，评分
- businessHours：String，营业时间
- description：String，简介

5.6.2 项目表（Project）
- projectId：String，唯一标识
- studioId：String，工作室ID
- name：String，项目名称
- category：String，分类（ring/earring/pendant/decoration）
- duration：Number，时长（分钟）
- difficulty：String，难度（easy/medium/hard）
- price：Number，价格
- photos：Array<String>，成品照片
- description：String，项目描述

5.6.3 预约表（Booking）
- bookingId：String，唯一标识
- userId：String，用户ID
- studioId：String，工作室ID
- projectId：String，项目ID
- date：String，日期
- timeSlot：String，时间段
- peopleCount：Number，人数
- status：String，状态（pending/confirmed/completed/cancelled）
- deposit：Number，定金金额
- note：String，备注

5.6.4 作品表（Artwork）
- artworkId：String，唯一标识
- userId：String，用户ID
- bookingId：String，预约ID
- photos：Array<String>，作品照片
- description：String，制作心得
- createdAt：Timestamp

### 5.7 技术架构
- 前端：ArkTS + ArkUI
- 后端：华为 Cloud DB（Serverless）
- 存储：华为 Cloud Storage 存放照片
- 登录：华为 Account Kit（可选）
- 卡片：服务卡片框架

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为烧玻璃爱好者提供垂直的预约和作品记录平台，将解决找不到工作室和作品记录的问题，因为现有平台不够垂直。我们通过审核通过率和预约转化率来验证。

### 7.2 用户故事

7.2.1 Story 1：发现附近工作室
作为一个想体验烧玻璃的用户，我想找到附近的工作室，以便安排行程。

验收标准：
- 显示附近工作室地图
- 按距离排序
- 查看工作室详情（环境/项目/价格）
- 支持筛选（价格/评分）

7.2.2 Story 2：浏览和选择项目
作为一个用户，我想了解项目详情和难度，以便选择适合的款式。

验收标准：
- 项目分类浏览
- 查看项目详情（照片/时长/难度/价格）
- 款式选择（颜色/形状）
- 效果预览

7.2.3 Story 3：在线预约
作为一个用户，我想在线预约体验时间，以便确保有位置。

验收标准：
- 选择日期和时间段
- 填写人数
- 支付定金
- 收到预约确认
- 预约提醒

7.2.4 Story 4：到店核销
作为一个用户，我想到店后快速核销预约，以便开始体验。

验收标准：
- 生成预约二维码
- 工作室扫码核销
- 显示预约详情

7.2.5 Story 5：记录和分享作品
作为一个用户，我想记录完成的作品并分享，以便留下回忆。

验收标准：
- 上传作品照片
- 添加制作心得
- 生成分享卡片
- 分享到社交平台

### 7.3 边界情况与约束

7.3.1 边界情况
- 工作室满员：提示"该时段已约满，请选择其他时间"
- 取消预约：根据取消时间退还部分/全部定金
- 作品损坏：提供补做或退款选项

7.3.2 技术约束
- 地图服务依赖第三方
- 支付功能需要接入支付SDK

- 概率：中低
- 缓解：强调预约功能+作品记录，突出垂直价值
