# 水族箱参数记录（AquaLog）产品需求文档


## 1 执行摘要

我们正在为水族爱好者构建一款基于鸿蒙服务卡片的水族箱参数监测应用AquaLog，解决水族爱好者难以系统记录水质参数、容易错过维护节点的问题。提供全面的水质参数记录（基础+进阶）、换水/喂食/设备维护日志、智能异常预警功能，结合服务卡片实时状态展示，成为鸿蒙生态水族品类的专业工具。预期上架后30天内获得300+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
22-50岁的水族爱好者，包括观赏鱼养殖者、水草缸玩家、海水缸玩家，使用华为鸿蒙设备，需要定期监测和维护水族箱环境。

### 2.2 问题是什么
水族箱维护涉及多个参数监测（温度、pH、氨氮等）和定期任务（换水、喂食、设备维护），现有方案要么是纸质记录本（容易丢失、不便统计），要么是简单的备忘录（不够专业），缺少一款专为水族设计的、可记录多维度参数、智能预警异常、系统管理维护日志的专业工具。

### 2.3 为什么这是痛点
- 参数复杂：需要监测温度、pH、氨氮、亚硝酸盐等多个参数，新手难以掌握
- 异常风险：水质参数异常可能导致鱼只死亡，但难以及时发现
- 维护繁琐：换水、清洗过滤、喂食等任务需要按时完成，容易遗忘
- 数据分散：测试数据、维护记录分散在不同地方，无法分析趋势

### 2.4 证据
- 中国水族市场规模庞大，水族爱好者数量众多
- 水质测试是水族养护的核心环节
- 新手常因水质问题导致鱼只死亡，需要专业工具辅助
- 华为应用市场暂无专业的水族参数记录工具

## 5 解决方案概述

### 5.1 产品定位
AquaLog是一款基于鸿蒙服务卡片的水族箱参数监测应用，提供全面的水质参数记录、维护日志管理、智能异常预警功能。

### 5.2 核心用户流程

5.2.1 记录水质参数流程
测试水质 → 打开App → 选择水族箱 → 输入各项参数 → 保存记录

5.2.2 接收维护提醒流程
到达维护时间 → 服务卡片/通知栏显示提醒 → 点击完成 → 记录维护

5.2.3 查看异常预警流程
参数超出安全范围 → 服务卡片显示警告 → 通知推送 → 查看详情和建议

5.2.4 查看趋势分析流程
打开App → 进入趋势页 → 选择参数和时间范围 → 查看图表分析

### 5.3 功能模块

5.3.1 水族箱管理模块
- 添加水族箱：
  - 名称（如"客厅草缸"）
  - 类型（淡水缸/草缸/海水缸/虾缸）
  - 容量（升）
  - 开缸日期
  - 备注
- 水族箱列表：
  - 显示所有水族箱
  - 显示状态（正常/警告/危险）
  - 显示最近记录时间
- 水族箱详情：
  - 基本信息
  - 当前状态（基于最新记录）
  - 快捷记录入口
  - 维护日志

5.3.2 水质参数记录模块
- 基础参数：
  - 温度（°C）
  - pH值
  - 氨氮（NH3/NH4+，mg/L）
  - 亚硝酸盐（NO2-，mg/L）
- 进阶参数：
  - 硝酸盐（NO3-，mg/L）
  - 硬度（GH，dGH）
  - 碳酸盐硬度（KH，dKH）
  - 盐度（ppt，海水缸）
  - 磷酸盐（PO4，mg/L）
- 记录方式：
  - 手动输入数值
  - 选择测试品牌（不同品牌色卡标准不同）
  - 拍照记录测试色卡（可选）
  - 添加备注
- 安全范围：
  - 根据水族箱类型自动设定各参数安全范围
  - 超出范围时标记警告/危险

5.3.3 维护日志模块
- 换水记录：
  - 换水日期
  - 换水量（%或升）
  - 是否清洗过滤
  - 是否修剪水草
  - 备注
- 喂食记录：
  - 喂食时间
  - 饲料类型
  - 喂食量
  - 鱼只进食情况
- 设备维护：
  - 过滤棉清洗/更换
  - 滤材更换
  - 灯管更换
  - 加热棒检查
  - CO2钢瓶更换
  - 其他设备维护
- 其他记录：
  - 添加新鱼
  - 鱼只死亡/移除
  - 添加水草/造景调整
  - 用药记录

5.3.4 智能预警模块
- 异常检测：
  - 参数超出安全范围自动检测
  - 连续多日未记录提醒
  - 换水周期到期提醒
  - 设备维护周期提醒
- 预警方式：
  - 服务卡片显示状态（正常/警告/危险）
  - 通知栏推送
  - App内警告标识
- 处理建议：
  - 参数异常时提供处理建议
  - 链接到相关知识

5.3.5 趋势分析模块
- 参数趋势图：
  - 选择参数和时间范围（7天/30天/90天/1年）
  - 折线图展示变化趋势
  - 显示平均值、最高值、最低值
- 维护统计：
  - 换水频率统计
  - 喂食规律分析
  - 设备维护周期
- 健康评分：
  - 基于参数稳定性计算健康评分
  - 历史评分趋势

5.3.6 知识库模块
- 水质参数指南：
  - 各参数的意义和影响
  - 不同水族箱类型的标准范围
  - 参数调整方法
- 常见问题：
  - 水质浑浊处理
  - 藻类控制
  - 鱼病预防
- 维护指南：
  - 换水步骤
  - 过滤维护
  - 设备保养

5.3.7 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 水族箱数据、参数记录、维护日志云端同步（Cloud DB）
- 照片云端存储（Cloud Storage）
- 换机后登录自动恢复
- Wi-Fi下自动同步，移动网络手动同步

5.3.8 服务卡片
- 水质状态卡片：显示水族箱状态（正常/警告/危险）和关键参数
- 今日任务卡片：显示今日待完成的维护任务
- 快捷记录卡片：一键进入参数记录页面
- 异常预警卡片：参数异常时显示警告信息

- 启动页：隐私政策弹窗 → 华为账号登录
- 首页（Tab1）：水族箱列表 + 快捷记录 + 状态概览
- 记录（Tab2）：参数记录 + 维护日志

### 5.6 数据模型

5.6.1 水族箱表（Aquarium）
- aquariumId：String，唯一标识
- userId：String，所属用户
- name：String，名称
- type：String，类型（freshwater/planted/marine/shrimp）
- volume：Number，容量（L）
- setupDate：String，开缸日期
- safeRanges：Object，各参数安全范围
- status：String，状态（normal/warning/danger）
- createdAt：Timestamp

5.6.2 参数记录表（ParameterRecord）
- recordId：String，唯一标识
- aquariumId：String，水族箱ID
- date：String，日期
- time：String，时间
- temperature：Number，温度
- ph：Number，pH值
- ammonia：Number，氨氮
- nitrite：Number，亚硝酸盐
- nitrate：Number，硝酸盐
- gh：Number，硬度
- kh：Number，碳酸盐硬度
- salinity：Number，盐度
- phosphate：Number，磷酸盐
- photoUrl：String，测试照片URL
- note：String，备注
- createdAt：Timestamp

5.6.3 维护日志表（MaintenanceLog）
- logId：String，唯一标识
- aquariumId：String，水族箱ID
- type：String，类型（waterChange/feeding/filter/light/co2/other）
- date：String，日期
- details：Object，详细信息
  - waterChange：{percentage, volume, filterCleaned}
  - feeding：{foodType, amount, feedingResponse}
  - filter：{filterType, action}
  - other：{description}
- note：String，备注
- createdAt：Timestamp

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为水族爱好者提供专业参数记录+智能预警+维护日志的工具，将解决水质管理困难和维护任务遗忘的问题，因为现有方案要么不够专业要么容易遗漏。我们通过审核通过率和记录使用率来验证。

7.2.1 Story 1：添加和管理水族箱
作为一个水族爱好者，我想添加我的水族箱并设置参数，以便系统管理。

验收标准：
- 可添加多个水族箱
- 设置名称、类型、容量、开缸日期
- 自动设定各参数安全范围
- 显示水族箱列表和状态
- 支持编辑和删除

7.2.2 Story 2：记录水质参数
作为一个水族爱好者，我想记录全面的水质参数，以便追踪水质变化。

验收标准：
- 支持基础参数（温度/pH/氨氮/亚硝酸盐）
- 支持进阶参数（硝酸盐/硬度/盐度/磷酸盐）

### 7.3 边界情况与约束

7.3.1 边界情况
- 多日未记录：提示"已XX天未记录水质"
- 参数严重异常：标记危险状态，强烈建议采取措施
- 无网络时：本地保存，恢复网络后同步
- 多水族箱：分别管理和记录

7.3.2 技术约束
- 图表渲染性能

- Cloud DB免费额度需监控
