# 孕期体重曲线管理（MamaTrack）产品需求文档


## 1 执行摘要

我们正在为孕妈妈构建一款基于鸿蒙服务卡片的孕期体重管理应用MamaTrack，解决孕期体重监测困难、不知如何控制体重的问题。提供体重记录（手动+运动健康同步+拍照）、多维度曲线对比（个人/标准/群体）、家人共享查看功能，结合服务卡片周增重提醒，成为鸿蒙生态母婴健康品类的专业工具。预期上架后30天内获得400+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
22-40岁的孕妈妈，处于孕期（1-40周），关注体重变化，希望科学管理孕期增重，使用华为鸿蒙设备。

### 2.2 问题是什么
孕期体重管理是产检的重要指标，但现有方案要么是纸质记录（容易丢失、不便查看趋势），要么是通用健康App（缺少孕期专用功能），缺少一款专为孕期设计的、可对比标准范围、可家人共享的体重管理工具。同时，孕妈妈希望记录孕期身体变化，但缺少系统的拍照记录功能。

### 2.3 为什么这是痛点
- 监测困难：需要每周记录体重，但容易忘记或丢失记录
- 标准不清：不知道增重多少是正常范围，盲目焦虑或忽视
- 对比缺失：无法直观看到自己的增重是否在合理区间
- 家人关心：丈夫/父母关心孕妈妈健康，但无法及时了解体重变化
- 变化记录：孕期身体变化珍贵，缺少系统的拍照记录方式

### 2.4 证据
- 中国每年新生儿超1000万，孕妈妈群体庞大
- 孕期体重管理是产检必查项目，医生会关注增重情况
- 孕妈妈普遍关注体重变化，"孕期增重多少正常"是高频搜索问题
- 华为应用市场暂无专业的孕期体重管理工具
- 华为运动健康有孕期模式，但缺少专业的体重曲线分析

## 5 解决方案概述

### 5.1 产品定位
MamaTrack是一款基于鸿蒙服务卡片的孕期体重管理应用，提供体重记录（手动+运动健康同步+拍照）、多维度曲线对比（个人/标准/群体）、家人共享查看功能。

### 5.2 核心用户流程

5.2.1 初始化设置流程
打开App → 输入孕前信息（身高/孕前体重/预产期/BMI） → 计算标准增重范围 → 进入主界面

5.2.2 记录体重流程
称重 → 打开App → 手动输入或授权同步华为运动健康 → 自动计算周增重 → 查看曲线位置

5.2.3 查看曲线对比流程
打开App → 查看体重曲线页 → 切换对比模式（个人/标准/群体） → 了解当前状态

5.2.4 拍照记录流程
打开App → 点击"孕期记录" → 拍照（正面/侧面） → 添加周数和备注 → 保存

5.2.5 家人共享流程
打开App → 进入设置 → 邀请家人（通过华为账号） → 家人接受邀请 → 家人可查看体重曲线和记录

### 5.3 功能模块

5.3.1 初始化设置模块
- 基本信息：
  - 身高（cm）
  - 孕前体重（kg）
  - 预产期（自动计算孕周）
  - 孕前BMI（自动计算）
- 标准增重计算：
  - 根据孕前BMI计算推荐增重范围
  - BMI<18.5：建议增重12.5-18kg
  - BMI 18.5-24.9：建议增重11.5-16kg
  - BMI 25-29.9：建议增重7-11.5kg
  - BMI≥30：建议增重5-9kg
  - 显示每周推荐增重（0.3-0.5kg/周）

5.3.2 体重记录模块
- 记录方式：
  - 手动输入：输入体重数值
  - 华为运动健康同步：授权读取体重数据
  - 自动计算：孕周、距上次增重、总增重、周平均增重
- 记录信息：
  - 体重（kg）
  - 日期时间
  - 孕周（自动计算）
  - 备注（如"早晨空腹""产检后"）
- 记录提醒：
  - 每周提醒称重（可设置周几）
  - 服务卡片显示"本周还未记录体重"
- 记录列表：按时间倒序展示所有记录

5.3.3 体重曲线模块
- 个人曲线：
  - 体重随孕周变化曲线
  - 标注每次记录点
  - 显示当前孕周和体重
- 标准范围对比：
  - 显示推荐增重范围上下限曲线
  - 个人曲线与标准范围对比
  - 当前位置评估（正常/偏低/偏高）
- 群体对比（匿名统计）：
  - 同孕周群体平均体重曲线
  - 同BMI群体平均增重曲线
  - 同龄群体对比
  - 显示个人在群体中的百分位
- 图表交互：
  - 缩放查看细节
  - 点击数据点查看详情
  - 切换显示模式（体重/增重）

5.3.4 孕期记录模块
- 拍照记录：
  - 正面照
  - 侧面照
  - 自动关联孕周
  - 添加文字备注
- 照片对比：
  - 选择两张照片对比
  - 生成变化对比图
  - 显示孕肚变化
- 时间轴：
  - 按孕周展示所有照片
  - 生成孕期变化 slideshow
- 导出分享：
  - 生成孕期变化长图
  - 导出为视频（V1.1）

5.3.5 数据分析模块
- 增重分析：
  - 总增重（当前-孕前）
  - 周平均增重
  - 最近4周增重趋势
  - 距离推荐范围差距
- 健康评估：
  - 当前状态（正常/偏低/偏高）
  - 建议调整方向
  - 预产期预估总增重
- 产检记录（可选）：
  - 记录产检体重（与自测对比）
  - 记录其他产检指标

5.3.6 家人共享模块
- 邀请家人：
  - 通过华为账号搜索邀请
  - 生成邀请码
- 共享权限：
  - 查看体重曲线
  - 查看孕期记录
  - 接收周增重提醒
  - 不可修改数据（仅查看）
- 共享管理：
  - 查看已共享家人列表
  - 取消共享

5.3.7 知识库模块
- 孕期增重指南：
  - 各阶段增重标准
  - 如何控制体重
  - 营养建议
- 常见问题：
  - 增重过快怎么办
  - 增重过慢怎么办
  - 体重波动正常吗
- 产检知识：
  - 各孕周产检项目
  - 体重相关指标解读

5.3.8 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 体重数据、孕期记录、照片云端同步（Cloud DB + Cloud Storage）
- 家人共享基于华为账号体系
- 换机后登录自动恢复
- Wi-Fi下自动同步，移动网络手动同步

5.3.9 服务卡片
- 本周体重卡片：显示本周体重、周增重、状态评估
- 记录提醒卡片：显示"本周还未记录体重"或"距离下次产检还有X天"
- 快捷记录卡片：一键进入体重记录页面
- 孕期周数卡片：显示当前孕周和宝宝发育提示

### 5.6 数据模型

5.6.1 孕期档案表（PregnancyProfile）
- profileId：String，唯一标识
- userId：String，用户ID
- height：Number，身高（cm）
- preWeight：Number，孕前体重（kg）
- preBMI：Number，孕前BMI
- dueDate：String，预产期
- startDate：String，建档日期
- targetGainMin：Number，推荐增重下限（kg）
- targetGainMax：Number，推荐增重上限（kg）
- status：String，状态（active/completed）
- createdAt：Timestamp

5.6.2 体重记录表（WeightRecord）
- recordId：String，唯一标识
- profileId：String，档案ID
- weight：Number，体重（kg）
- date：String，日期
- week：Number，孕周
- source：String，来源（manual/health）
- note：String，备注
- createdAt：Timestamp

5.6.3 孕期记录表（PregnancyLog）
- logId：String，唯一标识
- profileId：String，档案ID
- week：Number，孕周
- frontPhotoUrl：String，正面照URL
- sidePhotoUrl：String，侧面照URL
- note：String，备注
- createdAt：Timestamp

5.6.4 家人共享表（FamilyShare）
- shareId：String，唯一标识
- profileId：String，档案ID
- ownerId：String，孕妈妈用户ID
- familyUserId：String，家人用户ID
- status：String，状态（active/revoked）
- createdAt：Timestamp

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为孕妈妈提供专业的体重记录+多维度对比+家人共享的工具，将解决孕期体重管理困难和家人关心无法传递的问题，因为现有方案要么不够专业要么缺少共享功能。我们通过审核通过率和记录使用率来验证。

### 7.2 用户故事

7.2.1 Story 1：初始化孕期档案
作为一个孕妈妈，我想输入基本信息并了解推荐增重范围，以便科学管理孕期体重。

验收标准：
- 输入身高、孕前体重、预产期
- 自动计算孕前BMI
- 根据BMI显示推荐增重范围
- 显示每周推荐增重

7.2.2 Story 2：记录体重
作为一个孕妈妈，我想方便地记录体重，以便追踪变化。

验收标准：
- 支持手动输入体重
- 支持授权同步华为运动健康数据
- 自动计算孕周、总增重、周增重
- 可添加备注
- 每周提醒称重

7.2.3 Story 3：查看曲线对比
作为一个孕妈妈，我想对比个人曲线和标准/群体曲线，以便了解体重是否正常。

验收标准：
- 显示个人体重曲线
- 显示推荐增重范围上下限
- 显示同孕周/同BMI群体平均曲线
- 显示当前状态评估
- 支持切换显示模式

7.2.4 Story 4：拍照记录孕期
作为一个孕妈妈，我想拍照记录孕期身体变化，以便回顾珍贵时刻。

验收标准：
- 支持正面/侧面拍照
- 自动关联孕周
- 可添加备注
- 支持照片对比
- 按时间轴展示
- 可导出分享

7.2.5 Story 5：家人共享查看
作为一个孕妈妈，我想让家人查看我的体重变化，以便让他们了解我和宝宝的健康状况。

### 7.3 边界情况与约束

7.3.1 边界情况
- 产后使用：可标记"已分娩"，转为产后恢复模式（V1.1）
- 双胞胎/多胞胎：提供多胎增重标准选项
- 运动健康无数据：提示手动输入
- 体重波动大：提示"建议固定时间称重（如早晨空腹）"

7.3.2 技术约束
- 华为运动健康数据授权需用户确认
- 群体对比数据基于匿名统计，需积累一定用户量
- 照片占用存储空间需压缩
- Cloud DB免费额度需监控
