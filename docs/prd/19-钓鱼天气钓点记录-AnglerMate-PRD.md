# 钓鱼天气+钓点记录（AnglerMate）产品需求文档


## 1 执行摘要

我们正在为钓鱼爱好者构建一款基于鸿蒙意图框架的钓鱼辅助应用AnglerMate，解决钓鱼人需要综合天气、气压、潮汐、月相等多维度数据判断鱼情，以及记录钓点和渔获成果的需求。提供钓鱼指数预测、钓点GPS记录、渔获档案管理功能，纯个人工具无社交。预期上架后30天内获得300+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
25-55岁的钓鱼爱好者，包括休闲垂钓者和半专业钓手，使用华为鸿蒙设备，需要综合判断鱼情和记录钓鱼成果。

### 2.2 问题是什么
钓鱼人需要综合温度、湿度、气压、风速、潮汐、月相等多维度数据来判断"今天适不适合钓鱼""去哪里钓"。现有方案要么是通用天气App（缺少钓鱼指数和气压数据），要么是专业钓鱼App（功能复杂、广告多），缺少一款简洁、专业、无干扰的钓鱼天气工具。同时，钓点位置和渔获成果的记录分散在备忘录或相册，难以系统回顾。

### 2.3 为什么这是痛点
- 决策难：钓鱼需要综合多个气象指标，普通天气App无法提供钓鱼指数
- 数据缺失：气压是影响鱼情的关键指标，但大多数天气App不显示
- 海钓/夜钓特殊需求：潮汐和月相对海钓、夜钓至关重要，获取渠道分散
- 记录分散：钓点位置记在手机地图，渔获照片在相册，缺少统一档案
- 回顾困难：一年钓了多少鱼、哪个钓点效果最好，没有数据支撑

### 2.4 证据
- 中国钓鱼人群超1亿，是庞大的垂直用户群体
- 钓鱼类App在应用市场有稳定下载量，证明需求真实
- 钓鱼人普遍关注气压变化，"气压1000以上好钓鱼"是常识
- 海钓人群对潮汐表有刚性需求
- 华为应用市场暂无简洁专业的钓鱼天气工具

- 主要目标：成功上架华为应用市场，获得鸿蒙开发者激励计划奖励
- 次要目标：填补鸿蒙生态钓鱼天气工具的空白

- 中国钓鱼人群超1亿，垂直用户基数大

- 意图框架可支持场景化提醒
- 简洁工具类应用审核友好


## 5 解决方案概述

### 5.1 产品定位
AnglerMate是一款基于鸿蒙意图框架的钓鱼辅助应用，提供钓鱼天气（温度/湿度/气压/风速/钓鱼指数）、潮汐/月相（海钓/夜钓）、钓点GPS记录、渔获档案管理功能。纯个人工具，无社交功能。

### 5.2 核心用户流程

5.2.1 查看钓鱼天气流程
打开App → 首页显示当前位置钓鱼天气 → 查看钓鱼指数、气压、温度、湿度、风速 → 查看未来24小时趋势 → 决定出钓计划

5.2.2 查看潮汐/月相流程
打开App → 切换到潮汐/月相页 → 选择位置（沿海/湖泊） → 查看潮汐表或月相信息

5.2.3 记录钓点流程
到达钓点 → 打开App → 点击"记录钓点" → 自动获取GPS位置 → 填写钓点名称、类型、备注 → 保存

5.2.4 记录渔获流程
钓完鱼 → 打开App → 选择钓点 → 点击"记录渔获" → 填写鱼种、重量、数量 → 拍照 → 保存

5.2.5 查看档案流程
打开App → 进入档案页 → 查看钓点列表/渔获记录/统计数据

### 5.3 功能模块

5.3.1 钓鱼天气模块
- 当前天气：
  - 温度、湿度、气压（hPa）、风速风向
  - 钓鱼指数（1-5星，综合计算）
  - 天气状况（晴/阴/雨等）
- 24小时趋势：
  - 温度曲线
  - 气压曲线（钓鱼关键）
  - 钓鱼指数变化
- 7天预报：
  - 每日钓鱼指数
  - 温度范围
  - 天气状况
- 天气预警：恶劣天气提醒
- 数据来源：接入第三方天气API（如和风天气、OpenWeatherMap）

5.3.2 潮汐与月相模块
- 潮汐表（海钓）：
  - 选择沿海位置
  - 显示当日潮汐时间（涨潮/退潮/平潮）
  - 显示潮高数据
  - 未来7天潮汐预报
- 月相（夜钓）：
  - 当前月相（新月/上弦/满月/下弦）
  - 月出月落时间
  - 月光亮度
  - 未来月相日历
- 数据来源：接入第三方潮汐/天文API

5.3.3 钓点记录模块
- 记录钓点：
  - 自动获取GPS坐标
  - 填写钓点名称
  - 选择钓点类型（河流/湖泊/水库/池塘/海洋）
  - 填写备注（如"鲫鱼多""好停车"）
  - 拍照记录环境
- 钓点列表：
  - 地图模式：在地图上显示所有钓点
  - 列表模式：按添加时间/距离排序
  - 钓点详情：位置、类型、备注、照片、关联渔获记录
- 钓点导航：一键调起地图App导航
- 钓点编辑：修改名称、类型、备注
- 钓点删除：支持删除（二次确认）

5.3.4 渔获记录模块
- 记录渔获：
  - 选择钓点（从已记录钓点中选择）
  - 选择日期时间（默认当前）
  - 填写鱼种（从预设列表选择或自定义）
  - 填写重量（kg）
  - 填写数量
  - 填写钓法（手竿/海竿/路亚等）
  - 填写饵料
  - 填写天气状况（自动填充或手动修改）
  - 填写备注
  - 拍照记录（最多5张）
- 渔获列表：
  - 按时间倒序展示
  - 显示缩略图、鱼种、重量、日期
  - 筛选：按钓点/鱼种/日期筛选
- 渔获详情：
  - 查看完整信息
  - 查看照片
  - 关联钓点信息
- 渔获编辑：修改信息
- 渔获删除：支持删除

5.3.5 数据统计模块
- 总览统计：
  - 总钓获次数
  - 总钓获重量
  - 总钓获数量
  - 最常去的钓点TOP3
  - 最常钓的鱼种TOP3
- 年度统计：
  - 年度钓获次数/重量/数量
  - 月度分布图表
  - 鱼种分布饼图
  - 钓点分布
- 单次最佳：
  - 单尾最重记录
  - 单次最多数量记录
  - 单次最大总重记录

5.3.6 意图框架模块
- 到达钓点提醒：
  - 用户设置"到达XX钓点时提醒我记录"
  - 到达钓点附近（100米内）时系统推送通知
  - 点击通知直接进入记录渔获页面
- 钓鱼天气提醒：
  - 用户设置"钓鱼指数5星时提醒我"
  - 系统监测到钓鱼指数达到5星时推送通知
- 潮汐提醒（海钓）：
  - 用户设置"涨潮前30分钟提醒我"
  - 系统提前推送通知

5.3.7 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 钓点数据、渔获记录、照片云端同步（Cloud DB + Cloud Storage）
- 换机后登录自动恢复
- Wi-Fi下自动同步，移动网络手动同步

5.3.8 服务卡片
- 今日钓鱼指数卡片：负一屏显示今日钓鱼指数和气压
- 最近钓点卡片：显示最近去过的钓点，点击直接导航
- 快捷记录卡片：一键进入记录渔获页面

### 5.4 鸿蒙特性利用清单

| 云数据库 Cloud DB | 钓点/渔获数据同步 | P0 |

### 5.5 页面结构
- 启动页：隐私政策弹窗 → 华为账号登录
- 首页（Tab1）：当前钓鱼天气 + 24小时趋势 + 7天预报
- 潮汐/月相（Tab2）：潮汐表/月相信息
- 钓点（Tab3）：地图/列表 + 记录钓点
- 渔获（Tab4）：渔获列表 + 记录渔获 + 统计
- 我的（Tab5）：意图提醒设置、云同步设置、隐私政策

### 5.6 数据模型

5.6.1 钓点表（FishingSpot）
- spotId：String，唯一标识
- userId：String，所属用户
- name：String，钓点名称
- type：String，类型（river/lake/reservoir/pond/sea）
- latitude：Number，纬度
- longitude：Number，经度
- note：String，备注
- photos：Array<String>，照片URL数组
- createdAt：Timestamp
- updatedAt：Timestamp

5.6.2 渔获记录表（CatchRecord）
- recordId：String，唯一标识
- userId：String，所属用户
- spotId：String，钓点ID
- date：String，日期（YYYY-MM-DD）
- time：String，时间（HH:MM）
- fishSpecies：String，鱼种
- weight：Number，重量（kg）
- count：Number，数量
- method：String，钓法
- bait：String，饵料
- weather：String，天气状况
- temperature：Number，温度
- pressure：Number，气压
- note：String，备注
- photos：Array<String>，照片URL数组
- createdAt：Timestamp

5.6.3 意图提醒设置表（IntentSetting）
- settingId：String，唯一标识
- userId：String，所属用户
- type：String，提醒类型（arrival/weather/tide）
- spotId：String，关联钓点ID（仅arrival类型）
- condition：Object，触发条件
- isEnabled：Boolean，是否启用
- createdAt：Timestamp

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为钓鱼爱好者提供综合天气数据（含气压/潮汐/月相）+ 钓点记录 + 渔获档案 + 意图提醒的组合工具，将解决钓鱼人需要多个App查数据和记录分散的问题，因为现有方案要么数据不全要么功能复杂。我们通过审核通过率和钓点记录量来验证。

### 7.2 用户故事

7.2.1 Story 1：查看钓鱼天气
作为一个钓鱼人，我想查看当前位置的钓鱼指数、气压、温度等综合天气数据，以便决定是否出钓。

验收标准：
- 首页显示当前位置温度、湿度、气压（hPa）、风速风向
- 显示钓鱼指数（1-5星）
- 显示24小时温度/气压趋势图
- 显示7天钓鱼指数预报
- 恶劣天气显示预警提示
- 数据加载时间<3秒
- 支持手动刷新

7.2.2 Story 2：查看潮汐和月相
作为一个海钓/夜钓爱好者，我想查看潮汐表和月相信息，以便选择最佳出钓时间。

验收标准：
- 潮汐页显示当日涨潮/退潮/平潮时间
- 显示潮高数据
- 显示未来7天潮汐预报
- 月相页显示当前月相
- 显示月出月落时间
- 显示未来月相日历
- 支持选择不同沿海位置查看潮汐

7.2.3 Story 3：记录钓点
作为一个钓鱼人，我想记录我去过的钓点位置和相关信息，以便日后复访。

验收标准：
- 自动获取当前GPS坐标
- 填写钓点名称（必填）
- 选择钓点类型（河流/湖泊/水库/池塘/海洋）
- 填写备注（可选）
- 拍照记录环境（可选，最多5张）
- 地图模式显示所有钓点位置
- 列表模式按时间/距离排序
- 点击钓点可导航
- 支持编辑和删除

7.2.4 Story 4：记录渔获
作为一个钓鱼人，我想记录每次钓鱼的渔获成果，以便建立钓鱼档案。

验收标准：
- 选择钓点（从已记录钓点中选择）
- 选择日期时间（默认当前）
- 选择或填写鱼种
- 填写重量（kg）和数量
- 填写钓法和饵料（可选）
- 天气状况自动填充或手动修改
- 填写备注（可选）
- 拍照记录（可选，最多5张）
- 渔获列表按时间倒序展示
- 支持按钓点/鱼种/日期筛选
- 支持编辑和删除

7.2.5 Story 5：查看数据统计
作为一个钓鱼人，我想查看我的钓鱼数据统计，以便回顾成果和分析规律。

验收标准：
- 显示总钓获次数/重量/数量
- 显示最常去的钓点TOP3
- 显示最常钓的鱼种TOP3
- 年度统计：月度分布图表、鱼种分布饼图
- 显示单次最佳记录（最重/最多）

7.2.6 Story 6：意图提醒
作为一个钓鱼人，我想设置到达钓点提醒和钓鱼指数提醒，以便不错过好时机。

验收标准：
- 可设置"到达XX钓点时提醒我记录渔获"
- 到达钓点附近100米时推送通知
- 可设置"钓鱼指数5星时提醒我出钓"
- 系统监测到指数达到时推送通知
- 可设置"涨潮前30分钟提醒我"（海钓）
- 所有提醒可开关

7.2.7 Story 7：华为账号与云同步
作为一个用户，我想我的钓点和渔获记录自动云端同步，以便换手机后不丢失数据。

验收标准：
- 华为账号一键登录
- 钓点数据、渔获记录、照片自动同步
- 换机登录后自动恢复
- 提供账号注销功能

### 7.3 边界情况与约束

7.3.1 边界情况
- GPS定位失败：提示手动选择位置
- 天气API请求失败：显示缓存数据，提示"数据可能不是最新"
- 无网络时：显示缓存数据，记录本地保存，恢复网络后同步
- 钓点数量过多：地图模式性能优化，列表分页加载
- 照片上传失败：本地保存，后台重试上传

7.3.2 技术约束
- 天气/潮汐数据依赖第三方API，需申请API Key并监控用量
- GPS定位精度受环境影响
- 意图框架的地理围栏精度约100米
- Cloud DB免费额度需监控

## 9 依赖与风险

### 9.1 依赖项
- 华为Account Kit接入审批
- 华为Cloud DB和Cloud Storage服务开通

### 9.2 风险与缓解

9.2.1 数据风险：天气/潮汐API不稳定或收费
- 概率：中
- 缓解：准备备用API源；监控API用量和费用

9.2.2 审核风险：被归类为"简单天气工具"
- 概率：中低
- 缓解：强调意图框架场景提醒、钓点记录、渔获档案的组合功能，突出垂直场景深度

9.2.3 定位风险：GPS定位不准确
- 概率：中（室内或信号差场景）
- 缓解：提示用户到室外开阔地带定位；支持手动调整位置

9.2.4 竞争风险：与现有钓鱼App竞争
- 概率：中
- 缓解：强调简洁无广告、鸿蒙意图框架、纯个人工具无社交的差异化


## 10 开放问题

10.1 天气/潮汐API选型？
- 倾向：和风天气（国内稳定，有气压数据）+ 第三方潮汐API（如国家海洋信息中心）

10.2 钓鱼指数算法如何计算？
- 倾向：综合气压（权重40%）、温度（20%）、湿度（15%）、风速（15%）、天气状况（10%），具体阈值参考钓鱼常识

10.3 是否支持离线查看天气？
- 倾向：支持缓存最近1次天气数据，无网络时显示缓存并提示

10.4 钓点地图使用哪个地图SDK？
- 倾向：华为Map Kit（原生鸿蒙支持好）

10.5 渔获照片是否压缩？
- 倾向：上传时压缩至单张500KB以内，节省存储和流量

## 12 隐私合规设计

12.1 独立隐私政策文本，首次启动弹窗展示，用户同意后方可继续
12.2 用户同意前不初始化任何SDK
12.3 位置权限仅在记录钓点场景按需申请，不后台持续采集
12.4 钓点GPS坐标属于个人位置信息，云端加密存储
12.5 隐私政策明确说明位置数据用途、天气API数据范围、第三方SDK信息
12.6 提供账号注销功能，注销后30天内删除所有云端数据
12.7 从主界面4次以内点击可访问隐私政策
12.8 第三方SDK披露清单包含Account Kit、Cloud DB、Cloud Storage、Intent Kit、Map Kit


## 13 审核风险评估

### 13.1 低风险项
- 垂直工具属性，功能明确
- 无UGC社区，无社交，无支付
- 无广告
- 意图框架是鸿蒙独有特性

### 13.2 需重点关注

- 意图框架场景提醒（到达钓点/钓鱼指数/潮汐）是鸿蒙独有体验
- 简洁专业无广告，区别于功能繁杂的竞品
- 纯个人工具无社交，隐私友好
