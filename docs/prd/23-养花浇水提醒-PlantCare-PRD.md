# 养花浇水提醒（PlantCare）产品需求文档


## 1 执行摘要

我们正在为植物爱好者构建一款基于鸿蒙服务卡片的智能养花助手应用PlantCare，解决用户经常忘记浇水、不了解植物养护知识的问题。提供固定周期+智能双模式提醒、植物百科、生长记录功能，结合服务卡片今日待浇水提醒，成为鸿蒙生态园艺品类的标杆应用。预期上架后30天内获得400+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
20-50岁的植物爱好者，包括室内绿植养护者、阳台花园种植者、多肉植物爱好者，使用华为鸿蒙设备，有养护植物但经常忘记照顾的经历。

### 2.2 问题是什么
养花人经常忘记浇水、施肥、换盆等养护节点，导致植物枯萎或生长不良。现有方案要么是简单的周期提醒App（不够智能，不能根据季节天气调整），要么是植物识别App（功能单一），缺少一款智能提醒+知识科普+生长记录的综合养花助手。

### 2.3 为什么这是痛点
- 遗忘频繁：生活节奏快，容易忘记植物养护
- 知识缺乏：不了解具体植物的养护需求（多久浇一次、喜阴还是喜阳）
- 季节变化：同一植物在不同季节浇水频率不同，固定提醒不够智能
- 无法回顾：植物生长过程没有记录，看不到养护成果

### 2.4 证据
- 中国家庭园艺市场持续增长，室内绿植普及率高
- "植物杀手"是社交媒体常见自嘲，证明养护困难普遍存在
- 园艺类App有稳定需求，但缺少结合鸿蒙特性的产品
- 服务卡片适合展示"今日待浇水"这类即时信息

## 5 解决方案概述

### 5.1 产品定位
PlantCare是一款基于鸿蒙服务卡片的智能养花助手，提供固定周期+智能双模式提醒、植物百科知识库、生长记录功能。

### 5.2 核心用户流程

5.2.1 添加植物流程
打开App → 点击"添加植物" → 选择植物种类（或自定义） → 设置提醒模式（固定周期/智能） → 设置参数 → 保存

5.2.2 接收提醒流程
到达提醒时间 → 服务卡片/通知栏显示"今日待浇水" → 点击完成浇水 → 记录浇水

5.2.3 查看百科流程
打开App → 进入植物详情 → 点击"百科" → 查看养护知识

5.2.4 记录生长流程
打开App → 选择植物 → 点击"记录生长" → 拍照+备注 → 保存

### 5.3 功能模块

5.3.1 植物管理模块
- 添加植物：
  - 从植物库选择（内置100+常见植物）
  - 自定义植物（名称/照片）
  - 设置植物昵称（如"客厅绿萝"）
  - 设置购买/领养日期
  - 设置植物位置（客厅/阳台/卧室等）
- 植物详情：
  - 植物照片
  - 基本信息（名称/昵称/位置/养护天数）
  - 下次浇水时间
  - 养护记录时间线
  - 生长记录相册
- 植物列表：
  - 按位置分组显示
  - 显示养护状态（健康/需浇水/需施肥）
  - 显示下次浇水倒计时
- 植物编辑：修改任何信息
- 植物删除：支持删除（二次确认）

5.3.2 智能提醒模块
- 提醒类型：
  - 浇水提醒
  - 施肥提醒
  - 换盆提醒
  - 修剪提醒
- 提醒模式：
  - 固定周期模式：设置固定天数（如每7天）
  - 智能模式：根据植物种类、季节、天气自动计算
- 智能算法：
  - 植物种类：不同植物基础频率不同（多肉14天/绿萝7天/蕨类5天）
  - 季节调整：夏季频率+30%，冬季频率-30%
  - 天气调整：雨天延后，晴天提前
  - 用户反馈：根据用户"提前浇水"或"延后浇水"行为学习调整
- 提醒方式：
  - 服务卡片显示今日待浇水
  - 通知栏推送
  - 提醒时间可设置（早/中/晚）
- 完成记录：
  - 点击"完成"记录养护
  - 可添加备注（如"浇透水""叶片喷雾"）
  - 可拍照记录
  - 可跳过（生病/出差等原因）

5.3.3 植物百科模块
- 百科内容：
  - 植物介绍（科属/原产地/特点）
  - 养护指南（浇水/光照/温度/湿度/施肥）
  - 常见问题（黄叶/烂根/虫害解决）
  - 繁殖方法
  - 适宜摆放位置
- 百科形式：
  - 图文结合
  - 步骤说明
  - 问题诊断流程图
- 内置植物库：
  - 100+常见室内植物
  - 按养护难度分类（新手/进阶/专家）
  - 按功能分类（净化空气/观赏/易养护）
  - 支持搜索

5.3.4 生长记录模块
- 记录生长：
  - 选择植物
  - 拍照（最多5张）
  - 添加文字记录（如"长出新叶子""开花了"）
  - 记录日期（默认当前）
- 生长相册：
  - 按时间倒序展示
  - 对比视图（选择两张照片对比）
  - 生成生长延时视频（V1.1）
- 生长统计：
  - 养护天数
  - 浇水次数
  - 生长记录数

5.3.5 养护统计模块
- 总览统计：
  - 植物总数
  - 今日待浇水数
  - 本周已完成养护数
  - 连续养护天数
- 植物统计：
  - 单株植物养护记录
  - 浇水频率趋势
  - 健康状态变化

5.3.6 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 植物数据、养护记录、生长记录云端同步（Cloud DB）
- 照片云端存储（Cloud Storage）
- 换机后登录自动恢复
- Wi-Fi下自动同步，移动网络手动同步

5.3.7 服务卡片
- 今日待浇水卡片：显示今日需要浇水的植物数量和列表
- 植物状态卡片：显示指定植物的状态和下次浇水时间
- 快捷操作卡片：一键完成浇水
- 卡片交互：点击卡片进入App对应页面，点击"完成"直接记录浇水

- 首页（Tab1）：今日待浇水 + 植物列表 + 快捷添加

### 5.6 数据模型

5.3.1 植物表（Plant）
- plantId：String，唯一标识
- userId：String，所属用户
- speciesId：String，植物种类ID（自定义则为空）
- nickname：String，昵称（如"客厅绿萝"）
- photoUrl：String，植物照片URL
- location：String，位置（客厅/阳台/卧室等）
- purchaseDate：String，购买日期
- reminderMode：String，提醒模式（fixed/smart）
- reminderSettings：Object，提醒设置
  - waterInterval：Number，浇水间隔（天）
  - fertilizeInterval：Number，施肥间隔（天）
- nextWaterDate：String，下次浇水日期
- nextFertilizeDate：String，下次施肥日期
- status：String，状态（healthy/needsWater/needsFertilizer）
- createdAt：Timestamp

5.3.2 养护记录表（CareRecord）
- recordId：String，唯一标识
- plantId：String，植物ID
- type：String，类型（water/fertilize/repot/prune）
- date：String，日期
- note：String，备注
- photos：Array<String>，照片URL数组
- createdAt：Timestamp

5.3.3 生长记录表（GrowthRecord）
- recordId：String，唯一标识
- plantId：String，植物ID
- date：String，日期
- content：String，文字记录
- photos：Array<String>，照片URL数组
- createdAt：Timestamp

5.3.4 植物百科表（PlantWiki）
- speciesId：String，唯一标识
- name：String，植物名称
- scientificName：String，学名
- family：String，科属
- origin：String，原产地
- description：String，植物介绍
- careGuide：Object，养护指南
  - water：String，浇水说明
  - light：String，光照需求
  - temperature：String，温度要求
  - humidity：String，湿度要求
  - fertilize：String，施肥说明
- commonIssues：Array<Object>，常见问题
- propagation：String，繁殖方法
- difficulty：String，养护难度（beginner/intermediate/expert）
- category：String，分类（foliage/flower/succulent/herb）

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为植物爱好者提供智能提醒+植物百科+生长记录的综合工具，将解决忘记养护和缺乏知识的问题，因为现有方案要么不够智能要么功能单一。我们通过审核通过率和提醒完成率来验证。

### 7.2 用户故事

7.2.1 Story 1：添加和管理植物
作为一个植物爱好者，我想添加我的植物并设置提醒，以便系统管理养护。

验收标准：
- 可从植物库选择或自定义添加
- 设置植物昵称和位置
- 选择固定周期或智能提醒模式
- 设置浇水/施肥间隔
- 显示植物列表和状态
- 支持编辑和删除

7.2.2 Story 2：接收智能提醒
作为一个容易忘记浇水的人，我想在需要养护时收到提醒，以便及时照顾植物。

验收标准：
- 服务卡片显示今日待浇水
- 通知栏推送提醒
- 支持固定周期和智能双模式
- 智能模式根据植物/季节/天气调整
- 可设置提醒时间
- 点击完成记录养护

7.2.3 Story 3：查看植物百科
作为一个不了解养护知识的人，我想查看植物百科，以便学习如何照顾植物。

验收标准：
- 内置100+植物百科
- 包含养护指南和常见问题
- 支持搜索和分类浏览
- 图文结合展示

7.2.4 Story 4：记录植物生长
作为一个想记录植物变化的人，我想拍照记录生长，以便回顾历程。

验收标准：
- 可拍照+文字记录
- 按时间展示生长相册
- 对比视图查看变化
- 显示养护统计

7.2.5 Story 5：华为账号与云同步
作为一个用户，我想我的植物数据自动同步，以便换手机不丢失。

验收标准：
- 华为账号一键登录
- 植物数据、养护记录、生长记录自动同步
- 换机登录后自动恢复
- 提供账号注销功能

### 7.3 边界情况与约束

7.3.1 边界情况
- 植物死亡：可标记"已仙逝"，停止提醒，保留记录
- 长时间未记录：提示"已XX天未记录，植物还好吗？"
- 智能提醒无天气数据：回退到固定周期
- 重复提醒：同一天多次浇水可合并记录

7.3.2 技术约束
- 天气API依赖第三方
- 照片占用存储空间需压缩
- Cloud DB免费额度需监控
