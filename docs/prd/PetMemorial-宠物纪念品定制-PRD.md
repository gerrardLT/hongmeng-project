# 宠物纪念品定制（PetMemorial）产品需求文档


## 1 执行摘要

我们正在为宠物主构建一款宠物纪念品定制应用PetMemorial，解决宠物主想为宠物制作纪念品但找不到专业渠道、不了解制作方式的问题。提供线上选择纪念品种类、预约到店采集（爪印/毛发）、追踪制作进度、记录宠物档案功能，结合服务卡片宠物生日/纪念日提醒，成为连接宠物主与纪念品工作室的专业平台。预期上架后30天内获得300+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
25-40岁的宠物主，养有猫/狗等宠物，将宠物视为家庭成员，重视情感纪念，使用华为鸿蒙设备。

### 2.2 问题是什么
宠物主希望为宠物制作纪念品（爪印相框、毛发项链、肖像画等），但面临以下问题：
- 不知道有哪些纪念品可以选择
- 找不到专业的宠物纪念品制作机构
- 担心采集过程对宠物造成应激
- 无法追踪制作进度
- 缺少记录宠物成长/回忆的方式

### 2.3 为什么这是痛点
- **情感价值高**：宠物被视为家人，纪念品承载深厚感情
- **信息匮乏**：宠物纪念品市场相对小众，信息分散
- **专业度要求**：需要了解如何安全采集宠物爪印/毛发
- **时效性**：希望在宠物健康时留下纪念

### 2.4 证据
- 宠物经济持续增长，宠物主消费意愿强
- "宠物纪念品""宠物爪印"搜索量上升
- 客单价300-1500元，用户付费意愿强
- 现有解决方案分散，缺少专业平台

## 4 战略背景

### 4.1 业务目标
- 主要目标：成功上架华为应用市场，获得鸿蒙开发者激励计划奖励
- 次要目标：填补鸿蒙生态宠物纪念品定制平台的空白

- 宠物经济持续增长
- 宠物主情感消费能力强

### 4.4 为什么是现在
- 鸿蒙开发者激励计划进行中

- 垂直领域应用审核友好


## 5 解决方案概述

### 5.1 产品定位
PetMemorial是一款宠物纪念品定制应用，提供纪念品种类展示、到店采集预约、制作进度追踪、宠物档案与纪念日管理功能。

### 5.2 核心用户流程

5.2.1 了解纪念品种类流程
打开App → 浏览纪念品种类 → 查看详情和案例 → 了解采集方式

5.2.2 选择和预约流程
选择纪念品 → 选择工作室 → 预约采集时间 → 填写宠物信息 → 确认预约

5.2.3 到店采集流程
到达工作室 → 出示预约码 → 专业采集（爪印/毛发） → 确认设计

5.2.4 追踪和记录流程
查看制作进度 → 收到完成通知 → 记录到宠物档案 → 分享成品

### 5.3 功能模块

5.3.1 纪念品种类模块
- 种类展示：
  - 爪印相框（立体爪印/平面印泥）
  - 毛发纪念品（毛发项链/毛发水晶/毛发画）
  - 宠物肖像画（手绘/数字绘画）
  - 宠物印章
  - 纪念首饰（爪印项链/毛发戒指）
- 详情介绍：
  - 制作工艺
  - 采集方法
  - 适合宠物类型
  - 制作周期
  - 价格区间
- 案例展示：
  - 成品照片
  - 用户晒单

5.3.2 工作室预约模块
- 工作室列表：
  - 附近工作室
  - 评分和评价
  - 服务项目
  - 环境照片
- 预约流程：
  - 选择日期时间
  - 选择纪念品类型
  - 填写宠物信息（名字/品种/性格特点）
  - 特殊需求备注（宠物怕生/需要安抚等）
  - 支付定金
- 预约管理：
  - 查看预约详情
  - 取消/修改预约
  - 预约提醒

5.3.3 制作进度模块
- 进度追踪：
  - 采集完成
  - 设计确认
  - 制作中
  - 质检完成
  - 待取货/已发货
- 进度通知：
  - 状态变更推送
  - 预计完成时间
  - 服务卡片展示

5.3.4 宠物档案模块
- 宠物信息：
  - 名字、品种、性别
  - 生日、到家日期
  - 照片相册
- 纪念记录：
  - 所有纪念品记录
  - 按时间展示
- 纪念日提醒：
  - 生日提醒
  - 到家纪念日
  - 纪念品制作纪念日

5.3.5 社区模块（V1.1）
- 作品展示墙
- 宠物故事分享

5.3.6 服务卡片
- 预约提醒卡片：显示 upcoming 采集预约
- 进度卡片：显示制作进度
- 纪念日卡片：提醒宠物生日/纪念日

### 5.4 鸿蒙特性利用清单

| 鸿蒙能力 | 应用场景 | 优先级 |
|----------|---------|--------|
| 服务卡片 | 预约提醒、进度展示、纪念日提醒 | P1 |
| 华为账号 Account Kit | 一键登录 | P2 |

### 5.5 页面结构
- 首页：推荐纪念品、宠物纪念日
- 探索：纪念品种类、案例展示
- 预约：工作室、预约管理
- 进度：制作进度追踪
- 档案：宠物档案、纪念记录
- 我的：个人资料、设置

### 5.6 数据模型

5.6.1 纪念品种类表（MemorialType）
- typeId：String，唯一标识
- name：String，名称
- category：String，分类（pawprint/fur/portrait/seal/jewelry）
- description：String，描述
- suitablePet：String，适合宠物类型
- duration：String，制作周期
- priceRange：String，价格区间
- photos：Array<String>，案例照片

5.6.2 宠物档案表（PetProfile）
- petId：String，唯一标识
- userId：String，用户ID
- name：String，宠物名字
- type：String，类型（cat/dog/other）
- breed：String，品种
- birthday：String，生日
- adoptDate：String，到家日期
- photos：Array<String>，照片

5.6.3 预约表（Booking）
- bookingId：String，唯一标识
- userId：String，用户ID
- petId：String，宠物ID
- studioId：String，工作室ID
- typeId：String，纪念品种类ID
- date：String，预约日期
- status：String，状态

### 5.7 技术架构
- 前端：ArkTS + ArkUI
- 后端：华为 Cloud DB（Serverless）
- 存储：华为 Cloud Storage 存放照片
- 登录：华为 Account Kit（可选）
- 卡片：服务卡片框架

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为宠物主提供专业的纪念品定制平台，将解决找不到专业渠道的问题，因为现有渠道分散且不够专业。我们通过审核通过率和预约转化率来验证。

### 7.2 用户故事

7.2.1 Story 1：浏览纪念品种类
作为一个宠物主，我想了解有哪些纪念品可以选择，以便为宠物选择合适的。

验收标准：
- 展示纪念品种类列表
- 查看每种纪念品的详情
- 查看案例照片
- 了解采集方式和注意事项

7.2.2 Story 2：创建宠物档案
作为一个宠物主，我想记录宠物的信息，以便管理纪念记录。

验收标准：
- 添加宠物信息（名字/品种/生日）
- 上传宠物照片
- 查看宠物档案
- 记录纪念日

7.2.3 Story 3：预约到店采集
作为一个宠物主，我想预约专业工作室进行采集，以便安全舒适地完成。

验收标准：
- 查看附近工作室
- 选择日期和时间段
- 填写宠物信息和特殊需求
- 支付定金
- 收到预约确认

7.2.4 Story 4：追踪制作进度
作为一个宠物主，我想了解纪念品的制作进度，以便安心等待。

验收标准：
- 查看当前制作阶段
- 状态变更推送通知
- 服务卡片展示进度

7.2.5 Story 5：纪念日提醒
作为一个宠物主，我想收到宠物生日/纪念日提醒，以便准备庆祝。

验收标准：
- 设置宠物生日和纪念日
- 提前提醒（3天/1天）
- 服务卡片显示 upcoming 纪念日

### 7.3 边界情况与约束

7.3.1 边界情况
- 宠物不配合采集：提供安抚建议或改期
- 制作延期：及时通知
- 成品不满意：提供修改服务

7.3.2 技术约束
- 纪念日提醒需要本地通知权限
