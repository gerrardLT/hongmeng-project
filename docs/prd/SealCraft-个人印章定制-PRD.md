# 个人印章定制（SealCraft）产品需求文档


## 1 执行摘要

我们正在为需要个人印章的用户构建一款印章定制应用SealCraft，解决用户找不到靠谱刻章店、不了解印章材质和字体、刻章流程不透明的问题。提供线上选择印章类型、设计字体排版、预览效果、预约到店/邮寄服务，结合服务卡片取件提醒，成为连接用户与刻章工作室的专业平台。预期上架后30天内获得400+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
22-45岁的个人用户，包括职场人士、书法爱好者、收藏爱好者，需要个人印章用于签名、收藏、书法等用途，使用华为鸿蒙设备。

### 2.2 问题是什么
个人需要印章时面临以下问题：
- 找不到靠谱的刻章店（街边店质量参差不齐）
- 不了解印章材质（铜/石/木/牛角等）的特点和价格
- 不清楚字体选择（篆书/隶书/楷书等）的效果
- 刻章流程不透明（不知道多久能取）
- 无法预览刻好后的效果

### 2.3 为什么这是痛点
- **专业性要求高**：印章涉及书法美学，普通用户不懂选择
- **质量难判断**：材质真假、刻工好坏难以辨别
- **时间不确定**：不知道多久能取，急用时不放心
- **效果不可见**：刻完才发现效果不好，无法修改

### 2.4 证据
- 印章定制在书法、收藏圈有稳定需求
- 闲鱼/淘宝印章定制销量可观
- 职场人士需要签名章、藏书章
- 现有解决方案分散，缺少专业平台

## 5 解决方案概述

### 5.1 产品定位
SealCraft是一款个人印章定制应用，提供印章类型选择、材质字体科普、效果预览、在线预约、制作进度追踪功能。

### 5.2 核心用户流程

5.2.1 了解印章知识流程
打开App → 浏览印章类型 → 了解材质特点 → 学习字体知识

5.2.2 设计和预约流程
选择印章类型 → 输入刻字内容 → 选择字体 → 预览效果 → 选择材质 → 预约到店/邮寄

5.2.3 制作和取件流程
查看制作进度 → 收到完成通知 → 到店取件/快递收货

### 5.3 功能模块

5.3.1 印章知识模块
- 印章类型：
  - 姓名章（方形/圆形）
  - 闲章（引首章/压角章）
  - 藏书章
  - 签名章
  - 收藏章
- 材质介绍：
  - 铜章（耐用/正式）
  - 寿山石（名贵/收藏）
  - 青田石（性价比）
  - 牛角（传统/温润）
  - 檀木（环保/雅致）
  - 每种材质的特点、价格、适用场景
- 字体介绍：
  - 篆书（传统/正式）
  - 隶书（古朴/稳重）
  - 楷书（清晰/现代）
  - 行书（流畅/个性）
  - 字体示例和适用场景

5.3.2 设计预览模块
- 刻字输入：
  - 输入刻字内容（1-4字）
  - 自动检测敏感字
- 字体选择：
  - 多种字体可选
  - 字体效果预览
- 排版设计：
  - 自动排版
  - 手动调整（位置/大小）
- 效果预览：
  - 3D预览效果
  - 印泥效果预览
  - 不同材质效果对比

5.3.3 工作室预约模块
- 工作室列表：
  - 附近工作室
  - 评分和评价
  - 擅长材质/字体
  - 作品展示
- 预约方式：
  - 到店自取
  - 邮寄服务
- 预约流程：
  - 选择日期时间（到店）
  - 填写收货地址（邮寄）
  - 确认设计稿
  - 支付定金/全款
- 预约管理：
  - 查看预约详情
  - 取消/修改预约
  - 取件提醒

5.3.4 制作进度模块
- 进度追踪：
  - 设计确认
  - 选材准备
  - 刻制中
  - 打磨修整
  - 质检完成
  - 待取件/已发货
- 进度通知：
  - 状态变更推送
  - 预计完成时间
  - 服务卡片展示

5.3.5 个人印章库模块
- 我的印章：
  - 所有定制印章记录
  - 印章照片
  - 使用场景记录
- 印蜕收藏：
  - 盖章效果拍照保存
  - 作品展示

5.3.6 服务卡片
- 取件提醒卡片：显示 upcoming 取件预约
- 进度卡片：显示制作进度
- 知识卡片：每日印章知识推荐

### 5.4 鸿蒙特性利用清单

| 鸿蒙能力 | 应用场景 | 优先级 |
|----------|---------|--------|
| 服务卡片 | 取件提醒、进度展示 | P1 |
| 华为账号 Account Kit | 一键登录 | P2 |

### 5.5 页面结构
- 首页：推荐印章类型、热门材质
- 知识：材质/字体科普、印章文化
- 设计：刻字、选字体、预览效果
- 预约：工作室、预约管理
- 进度：制作进度追踪
- 我的：印章库、个人资料

### 5.6 数据模型

5.6.1 印章类型表（SealType）
- typeId：String，唯一标识
- name：String，名称
- category：String，分类（name/leisure/book/signature/collection）
- description：String，描述
- suitableFor：String，适用场景
- priceRange：String，价格区间

5.6.2 材质表（Material）
- materialId：String，唯一标识
- name：String，名称
- description：String，描述
- features：String，特点
- priceRange：String，价格区间
- suitableFor：String，适用场景
- photos：Array<String>，材质照片

5.6.3 字体表（FontStyle）
- fontId：String，唯一标识
- name：String，名称
- description：String，描述
- style：String，风格描述
- sample：String，示例字

5.6.4 预约表（Booking）
- bookingId：String，唯一标识
- userId：String，用户ID
- studioId：String，工作室ID
- content：String，刻字内容
- fontId：String，字体ID
- materialId：String，材质ID
- typeId：String，印章类型ID
- status：String，状态
- deliveryType：String，取件方式（pickup/delivery）

### 5.7 技术架构
- 前端：ArkTS + ArkUI
- 后端：华为 Cloud DB（Serverless）
- 存储：华为 Cloud Storage 存放照片
- 登录：华为 Account Kit（可选）

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为印章需求者提供专业的设计预览和定制平台，将解决找不到靠谱刻章店和无法预览效果的问题，因为现有渠道不透明且效果不可见。我们通过审核通过率和预约转化率来验证。

### 7.2 用户故事

7.2.1 Story 1：了解印章知识
作为一个想刻章的用户，我想了解材质和字体的知识，以便做出合适的选择。

验收标准：
- 展示印章类型介绍
- 展示材质特点和价格
- 展示字体风格和示例
- 提供选择建议

7.2.2 Story 2：设计预览效果
作为一个用户，我想预览印章刻好后的效果，以便确认设计。

验收标准：
- 输入刻字内容
- 选择字体
- 实时预览效果
- 3D效果展示
- 印泥效果预览

7.2.3 Story 3：预约刻章服务
作为一个用户，我想预约靠谱的刻章店，以便确保质量。

验收标准：
- 查看附近工作室
- 查看工作室评价和作品
- 选择到店或邮寄
- 选择日期时间
- 支付定金

7.2.4 Story 4：追踪制作进度
作为一个用户，我想了解印章的制作进度，以便安排取件。

验收标准：
- 查看当前制作阶段
- 状态变更推送通知
- 显示预计完成时间
- 服务卡片展示进度

7.2.5 Story 5：管理个人印章
作为一个用户，我想记录我的印章，以便管理和展示。

验收标准：
- 查看所有定制印章
- 上传印章照片
- 记录使用场景
- 保存印蜕效果

### 7.3 边界情况与约束

7.3.1 边界情况
- 敏感字检测：自动检测并提示不能刻制的字
- 设计修改：刻制前可免费修改设计
- 成品不满意：提供重做或退款选项

7.3.2 技术约束
- 字体渲染需要优化性能
- 3D预览需要模型支持
