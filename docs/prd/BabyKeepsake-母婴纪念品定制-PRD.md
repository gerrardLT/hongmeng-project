# 母婴纪念品定制（BabyKeepsake）产品需求文档


## 1 执行摘要

我们正在为新手父母构建一款母婴纪念品定制应用BabyKeepsake，解决父母想为宝宝制作纪念品但找不到专业渠道、不了解制作流程的问题。提供线上选择纪念品种类、设计风格、预约到店采集、查看制作进度功能，结合服务卡片成长提醒，成为连接父母与纪念品工作室的专业平台。预期上架后30天内获得400+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
25-40岁的新手父母，宝宝年龄在0-3岁，重视仪式感，愿意为情感价值付费，使用华为鸿蒙设备。

### 2.2 问题是什么
父母希望为宝宝制作纪念品（手足印、胎毛画、乳牙盒等），但面临以下问题：
- 不知道有哪些纪念品可以选择
- 不了解制作流程和保存方法
- 找不到专业的制作机构
- 担心采集过程对宝宝不安全
- 无法追踪制作进度

### 2.3 为什么这是痛点
- **情感刚需**：父母希望记录宝宝成长的珍贵时刻
- **信息缺失**：不了解纪念品种类和制作方式
- **信任问题**：担心采集过程对宝宝有伤害
- **品质担忧**：网上购买成品质量参差不齐
- **进度焦虑**：制作周期长，不知道进展如何

### 2.4 证据
- 母婴纪念品在淘宝/小红书上销量可观
- "宝宝手足印""胎毛纪念品"是高频搜索词
- 父母愿意为情感价值支付溢价（客单价500-2000元）
- 现有解决方案分散，缺少专业平台

## 5 解决方案概述

### 5.1 产品定位
BabyKeepsake是一款母婴纪念品定制应用，提供纪念品种类展示、设计风格选择、到店采集预约、制作进度追踪、成长里程碑记录功能。

### 5.2 核心用户流程

5.2.1 了解纪念品种类流程
打开App → 浏览纪念品种类 → 查看详情和案例 → 了解制作流程

5.2.2 选择和预约流程
选择纪念品 → 选择设计风格 → 选择工作室 → 预约采集时间 → 确认预约

5.2.3 到店采集流程
到达工作室 → 出示预约码 → 专业采集（手足印/胎毛等） → 确认设计稿

5.2.4 追踪和收货流程
查看制作进度 → 收到完成通知 → 到店取货/快递收货 → 上传成品照片

### 5.3 功能模块

5.3.1 纪念品种类模块
- 种类展示：
  - 手足印相框（立体手足印/平面印泥）
  - 胎毛纪念品（胎毛画/胎毛笔/胎毛印章）
  - 乳牙保存盒
  - 出生纪念（出生证明框/脐带纪念品）
  - 成长时间轴
- 详情介绍：
  - 制作工艺
  - 保存方法
  - 适合年龄
  - 制作周期
  - 价格区间
- 案例展示：
  - 成品照片
  - 用户晒单
  - 制作视频

5.3.2 设计风格模块
- 风格选择：
  - 简约现代
  - 复古欧式
  - 卡通可爱
  - 中式传统
  - 个性定制
- 预览功能：
  - 上传宝宝照片
  - 选择风格预览效果
  - 调整配色和元素

5.3.3 工作室预约模块
- 工作室列表：
  - 附近工作室
  - 评分和评价
  - 服务项目
  - 环境照片
- 预约流程：
  - 选择日期时间
  - 选择纪念品类型
  - 填写宝宝信息（姓名/生日）
  - 特殊需求备注
  - 支付定金
- 预约管理：
  - 查看预约详情
  - 取消/修改预约
  - 预约提醒

5.3.4 制作进度模块
- 进度追踪：
  - 采集完成
  - 设计确认
  - 制作中
  - 质检完成
  - 待取货/已发货
- 进度通知：
  - 状态变更推送
  - 预计完成时间
  - 服务卡片展示

5.3.5 成长记录模块
- 里程碑记录：
  - 第一次采集手足印
  - 第一次剃胎毛
  - 第一颗乳牙脱落
  - 生日纪念
- 时间轴：
  - 按时间展示所有纪念品
  - 宝宝成长记录
- 分享功能：
  - 生成成长分享卡片
  - 分享到社交平台

5.3.6 知识库模块
- 采集指南：
  - 手足印采集注意事项
  - 胎毛保存方法
  - 乳牙脱落护理
- 保养知识：
  - 纪念品保养方法
  - 存放环境要求

5.3.7 服务卡片
- 预约提醒卡片：显示 upcoming 采集预约
- 进度卡片：显示制作进度
- 里程碑卡片：提醒宝宝成长节点

### 5.4 鸿蒙特性利用清单

| 鸿蒙能力 | 应用场景 | 优先级 |
|----------|---------|--------|
| 服务卡片 | 预约提醒、进度展示、里程碑提醒 | P1 |
| 华为账号 Account Kit | 一键登录 | P2 |
| 意图框架 | 到达工作室附近提醒 | P2 |

### 5.5 页面结构
- 首页：推荐纪念品、成长里程碑
- 探索：纪念品种类、案例展示
- 预约：工作室、预约管理
- 进度：制作进度追踪
- 记录：成长时间轴、作品相册
- 我的：个人资料、宝宝信息

### 5.6 数据模型

5.6.1 纪念品种类表（KeepsakeType）
- typeId：String，唯一标识
- name：String，名称
- category：String，分类（handprint/hair/tooth/birth/growth）
- description：String，描述
- suitableAge：String，适合年龄
- duration：String，制作周期
- priceRange：String，价格区间
- photos：Array<String>，案例照片

5.6.2 工作室表（Studio）
- studioId：String，唯一标识
- name：String，名称
- address：String，地址
- location：Object，经纬度
- services：Array<String>，服务项目
- rating：Number，评分
- photos：Array<String>，环境照片

5.6.3 预约表（Booking）
- bookingId：String，唯一标识
- userId：String，用户ID
- studioId：String，工作室ID
- typeId：String，纪念品种类ID
- babyName：String，宝宝姓名
- babyBirthday：String，宝宝生日
- date：String，预约日期
- status：String，状态
- designStyle：String，设计风格

5.6.4 进度表（Progress）
- progressId：String，唯一标识
- bookingId：String，预约ID
- stage：String，阶段
- status：String，状态
- updateTime：Timestamp
- note：String，备注

### 5.7 技术架构
- 前端：ArkTS + ArkUI
- 后端：华为 Cloud DB（Serverless）
- 存储：华为 Cloud Storage 存放照片

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为新手父母提供专业的母婴纪念品定制平台，将解决找不到专业渠道和无法追踪进度的问题，因为现有渠道分散且不够专业。我们通过审核通过率和预约转化率来验证。

### 7.2 用户故事

7.2.1 Story 1：浏览纪念品种类
作为一个新手妈妈，我想了解有哪些纪念品可以选择，以便为宝宝选择合适的。

验收标准：
- 展示纪念品种类列表
- 查看每种纪念品的详情
- 查看制作工艺和保存方法
- 查看案例照片
- 了解价格区间

7.2.2 Story 2：选择设计风格
作为一个用户，我想预览不同风格的效果，以便选择喜欢的设计。

验收标准：
- 多种风格可选（简约/复古/卡通/中式）
- 上传宝宝照片预览效果
- 调整配色和元素
- 保存设计偏好

7.2.3 Story 3：预约到店采集
作为一个用户，我想预约专业工作室进行采集，以便安全舒适地完成。

验收标准：
- 查看附近工作室
- 选择日期和时间段
- 填写宝宝信息
- 支付定金
- 收到预约确认和提醒

7.2.4 Story 4：追踪制作进度
作为一个用户，我想了解纪念品的制作进度，以便安心等待。

验收标准：
- 查看当前制作阶段
- 状态变更推送通知
- 显示预计完成时间
- 服务卡片展示进度

7.2.5 Story 5：记录成长里程碑
作为一个用户，我想记录宝宝的成长纪念品，以便回顾珍贵时刻。

验收标准：
- 记录每次纪念品制作
- 按时间轴展示
- 上传成品照片
- 生成分享卡片

### 7.3 边界情况与约束

7.3.1 边界情况
- 宝宝不配合采集：提供多次采集机会
- 制作延期：及时通知并说明原因
- 成品不满意：提供修改或重做选项

7.3.2 技术约束
- 图片预览需要优化性能
- 进度同步需要实时性
