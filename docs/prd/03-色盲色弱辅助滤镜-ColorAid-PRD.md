## 1. 执行摘要

ColorAid是一款专为色盲/色弱人群设计的实时色彩辅助应用，利用鸿蒙Core Vision Kit的端侧AI能力，通过手机摄像头实时分析并增强色彩对比度，帮助用户识别颜色、区分相似色彩，提升日常生活便利性。

**核心价值主张**: 让色盲/色弱用户"看见"原本难以区分的颜色，独立自信地应对日常生活中的色彩识别场景。

---

## 2. 问题陈述

### 2.1 目标用户痛点

色盲/色弱人群（全球约3亿人，中国约6000万人）在日常生活中面临诸多困扰：

- **交通出行**: 难以区分红绿灯（红绿色盲最常见）
- **购物选择**: 无法分辨衣服、水果、蔬菜的颜色
- **工作场景**: 图表、报表中的颜色编码难以识别
- **社交尴尬**: 无法准确描述颜色，造成沟通障碍
- **安全隐患**: 无法识别警示标志、药品颜色等

### 2.2 当前解决方案的不足

| 方案类型 | 问题 |
|---------|------|
| 特殊眼镜 | 价格昂贵（数千元）、佩戴不便、效果有限 |
| 手机滤镜App | 多为静态滤镜，缺乏实时性；色彩增强算法粗糙 |
| 人工协助 | 依赖他人，不独立，隐私性差 |

### 2.3 问题验证

- 华为应用市场搜索"色盲"，结果多为色盲测试工具，无专业辅助应用
- 现有App评分普遍低于3.5分，用户抱怨"延迟高"、"效果不明显"
- 色盲论坛中高频需求："实时识别颜色"、"增强对比度"、"简单好用"

## 5. 解决方案概述

### 5.1 核心功能

#### 功能1: 实时色彩滤镜
- 通过手机摄像头实时预览增强后的画面
- 支持多种色盲类型的针对性增强算法
- 可调节增强强度

#### 功能2: 颜色识别与播报
- 点击屏幕任意位置，识别该位置颜色
- 语音播报颜色名称（支持中文）
- 显示颜色的HEX/RGB值

#### 功能3: 色盲类型检测
- 内置简易色盲测试（石原图版）
- 根据测试结果推荐最适合的滤镜模式

#### 功能4: 拍照色彩分析
- 拍摄照片后分析画面中的主要颜色
- 标注各区域颜色名称
- 保存分析结果

#### 功能5: 服务卡片
- 负一屏快捷入口
- 一键开启实时滤镜
- 显示最近识别的颜色

### 5.2 核心用户流程

#### 流程1: 首次使用流程
```
打开App → 隐私政策同意 → 色盲类型检测 → 推荐滤镜模式 → 进入主界面
```

#### 流程2: 实时滤镜使用
```
主界面 → 选择滤镜模式 → 对准目标 → 实时查看增强效果 → 点击识别颜色 → 语音播报
```

#### 流程3: 拍照分析
```
点击拍照按钮 → 拍摄照片 → 自动分析主要颜色 → 标注颜色名称 → 保存/分享
```

### 5.3 技术架构

**前端**: 鸿蒙ArkUI  
**核心能力**:
- Core Vision Kit（端侧AI图像处理）
- 华为Account Kit（账号登录）
- 华为Cloud DB（保存用户设置）

**色彩增强算法**:
- 基于Daltonization算法的实时色彩转换
- 针对红绿色盲、蓝黄色盲、全色盲的不同增强策略

## 6. 用户故事

### Story 1: 色盲类型检测与推荐

**As a** 新用户  
**I want to** 快速检测我的色盲类型  
**So that** 应用能为我推荐最适合的滤镜模式

**Acceptance Criteria**:
- 提供5张石原图版色盲测试图
- 根据答题结果判断色盲类型（红绿色盲/蓝黄色盲/全色盲/正常）
- 自动推荐最适合的滤镜增强模式
- 用户可跳过测试，手动选择模式

---

### Story 2: 实时色彩滤镜

**As a** 色弱用户  
**I want to** 通过摄像头实时看到增强后的色彩  
**So that** 我能区分原本难以识别的颜色

**Acceptance Criteria**:
- 支持红绿色盲、蓝黄色盲、全色盲三种增强模式
- 实时预览延迟低于200ms（利用端侧AI）
- 可调节增强强度（1-10级）
- 支持前后摄像头切换
- 支持手电筒补光

---

### Story 3: 颜色识别与播报

**As a** 色弱用户  
**I want to** 点击屏幕识别特定位置的颜色  
**So that** 我能准确知道那是什么颜色

**Acceptance Criteria**:
- 点击屏幕任意位置，识别该位置3x3像素区域的主色调
- 语音播报颜色名称（如"深红色"、"浅绿色"）
- 显示颜色名称、HEX值、RGB值
- 播报音量可调节
- 支持关闭语音，仅显示文字

---

### Story 4: 拍照色彩分析

**As a** 用户  
**I want to** 拍摄照片并分析其中的颜色  
**So that** 我能保存和回顾颜色信息

**Acceptance Criteria**:
- 拍摄照片后自动分析画面中的主要颜色（最多5种）
- 在照片上标注各区域的颜色名称
- 保存分析结果到相册
- 支持分享分析结果

---

### Story 5: 服务卡片

**As a** 用户  
**I want to** 在负一屏快速开启滤镜  
**So that** 我不需要每次都打开App

**Acceptance Criteria**:
- 负一屏卡片显示"一键开启实时滤镜"按钮
- 点击直接跳转到App并启动滤镜
- 显示最近识别的3个颜色
- 卡片尺寸支持2x2和4x2两种规格

---

### Story 6: 华为账号与设置同步

**As a** 用户  
**I want to** 用华为账号登录并同步设置  
**So that** 换机后我的偏好设置不丢失

**Acceptance Criteria**:
- 首次启动显示隐私政策，需用户同意
- 支持华为账号一键登录
- 同步用户选择的色盲类型、滤镜强度等设置

## 14. 附录

### 14.1 色彩增强算法说明

**Daltonization算法原理**:
- 模拟色盲用户的视觉感知
- 将难以区分的颜色映射到可区分的颜色空间
- 保持整体画面自然度

**三种增强模式**:
1. **红绿色盲模式**: 增强红色/绿色对比度，使用蓝黄通道辅助区分
2. **蓝黄色盲模式**: 增强蓝色/黄色对比度，使用红绿通道辅助区分
3. **全色盲模式**: 转换为高对比度灰度，增强亮度差异
