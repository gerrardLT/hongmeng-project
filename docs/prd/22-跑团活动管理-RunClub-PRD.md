# 跑团活动管理（RunClub）产品需求文档


## 1 执行摘要

我们正在为跑步爱好者和跑团组织者构建一款基于鸿蒙碰一碰能力的跑团综合管理应用RunClub，解决跑团活动组织繁琐、签到麻烦、成员数据分散的问题。提供活动管理、训练计划、个人跑步记录、跑团排名统计功能，支持碰一碰签到和交换跑友名片，成为鸿蒙生态跑步社交品类的标杆应用。预期上架后30天内获得500+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
20-45岁的跑步爱好者，包括跑团成员、跑团组织者、个人跑者，使用华为鸿蒙设备，有参与或组织跑团活动的需求。

### 2.2 问题是什么
跑团活动组织涉及发布通知、报名统计、现场签到、成绩记录等多个环节，现有方案依赖微信群（信息刷屏、难以统计）+ 第三方运动App（功能分散），缺少一款专为跑团设计的综合管理工具。同时，跑团成员之间缺少便捷的名片交换方式，个人训练数据和跑团活动数据分散在不同平台。

### 2.3 为什么这是痛点
- 组织难：跑团组织者需要在微信群发通知、手动统计报名、现场点名签到，效率低
- 签到难：活动现场人数多，传统点名或二维码签到效率低，容易遗漏
- 数据散：个人训练记录在一个App，跑团活动在另一个平台，无法关联分析
- 社交弱：跑完活动后想认识新跑友，缺少自然的交换联系方式方式

### 2.4 证据
- 中国跑步人群超3亿，跑团数量庞大
- 跑步类App（Keep、悦跑圈）用户量巨大，但缺少跑团综合管理功能
- 跑团活动签到是组织者痛点，碰一碰秒级签到是刚需
- 华为运动健康生态对跑步应用有扶持

## 5 解决方案概述

### 5.1 产品定位
RunClub是一款基于鸿蒙碰一碰能力的跑团综合管理应用，提供活动管理、训练计划、个人跑步记录、跑团排名统计功能，支持碰一碰签到和交换跑友名片。

### 5.2 核心用户流程

5.2.1 创建活动流程
组织者打开App → 点击"创建活动" → 填写活动信息（时间/地点/距离/类型） → 发布活动 → 分享活动链接

5.2.2 报名活动流程
成员打开App → 浏览活动列表 → 点击报名 → 确认参与

5.2.3 碰一碰签到流程
到达活动现场 → 打开App → 点击"签到" → 手机碰触组织者设备 → 签到成功

5.2.4 记录成绩流程
跑步完成 → 点击"记录成绩" → 手动输入或使用华为运动健康数据 → 保存成绩

5.2.5 碰一碰交换名片流程
跑步结束 → 点击"交换名片" → 手机碰触对方设备 → 交换跑友名片

### 5.3 功能模块

5.3.1 活动管理模块
- 创建活动：
  - 活动名称
  - 活动时间（日期+时间）
  - 活动地点（地图选点）
  - 活动类型（例跑/拉练/比赛/休闲）
  - 跑步距离（5km/10km/半马/全马/自定义）
  - 活动描述
  - 报名截止时间
  - 人数限制（可选）
- 活动列表：
  - 按时间展示即将开始和进行中的活动
  - 显示报名人数/状态
- 活动详情：
  - 查看活动信息
  - 查看报名名单
  - 查看签到名单
  - 查看成绩排名
- 活动操作：
  - 编辑活动
  - 取消活动
  - 分享活动（生成海报或链接）
- 活动状态：未开始/报名中/进行中/已结束

5.3.2 报名管理模块
- 成员报名：点击报名，填写备注（如"配速5分30"）
- 报名列表：组织者查看所有报名人员
- 报名取消：成员可取消报名
- 报名提醒：活动前推送提醒

5.3.3 碰一碰签到模块
- 签到方式：
  - 组织者生成签到码
  - 成员手机碰触组织者设备完成签到
  - 支持离线签到（恢复网络后同步）
- 签到记录：
  - 显示签到时间
  - 显示签到位置
  - 签到状态（已签到/未签到）
- 补签功能：组织者可为迟到成员补签

5.3.4 成绩记录模块
- 手动记录：
  - 选择活动
  - 输入完成时间（时:分:秒）
  - 输入配速
  - 上传跑步轨迹截图（可选）
- 华为运动健康联动：
  - 授权读取华为运动健康数据
  - 自动匹配活动时间和跑步记录
  - 一键导入成绩
- 成绩列表：
  - 按活动展示所有成员成绩
  - 自动排名
  - 显示个人PB（个人最佳）

5.3.5 训练计划模块
- 创建计划：
  - 计划名称（如"半马备战计划"）
  - 计划周期（4周/8周/12周）
  - 每周训练安排（跑休/轻松跑/节奏跑/长距离）
  - 目标赛事（可选）
- 计划执行：
  - 每日训练提醒
  - 完成打卡
  - 记录实际完成情况
- 计划进度：可视化进度条和统计

5.3.6 个人跑步记录模块
- 跑步记录：
  - 自动同步华为运动健康跑步数据
  - 手动添加跑步记录
  - 显示距离/时间/配速/消耗
- 数据统计：
  - 周/月/年跑量统计
  - 配速趋势
  - 累计里程
- 个人成就：
  - 里程碑（100km/500km/1000km）
  - 连续跑步天数
  - 个人最佳成绩

5.3.7 跑团排名统计模块
- 成员排名：
  - 月跑量排名
  - 活动参与次数排名
  - 平均配速排名
  - 总里程排名
- 跑团统计：
  - 总成员数
  - 月总跑量
  - 月活动次数
  - 人均跑量
- 排行榜展示：TOP10榜单，支持查看完整排名

5.3.8 跑友名片模块
- 名片内容：
  - 头像
  - 昵称
  - 跑龄
  - 总跑量
  - 个人宣言
  - 联系方式（可选显示）
- 碰一碰交换：
  - 活动现场碰触交换名片
  - 保存到跑友录
- 跑友录：
  - 查看所有交换过的跑友
  - 查看跑友名片
  - 添加备注

5.3.9 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 跑团数据、活动数据、个人记录云端同步（Cloud DB）
- 支持多设备登录
- 换机后登录自动恢复

5.3.10 服务卡片
- 活动提醒卡片：显示即将开始的活动倒计时
- 今日训练卡片：显示今日训练计划
- 快捷签到卡片：一键进入签到页面

### 5.5 页面结构
- 启动页：隐私政策弹窗 → 华为账号登录
- 首页（Tab1）：即将开始的活动 + 今日训练 + 快捷入口
- 活动（Tab2）：活动列表 + 创建活动
- 跑团（Tab3）：成员列表 + 排名统计
- 记录（Tab4）：个人跑步记录 + 训练计划
- 我的（Tab5）：跑友录、名片设置、隐私政策

### 5.6 数据模型

5.6.1 跑团表（RunningClub）
- clubId：String，唯一标识
- name：String，跑团名称
- description：String，跑团介绍
- ownerId：String，团长用户ID
- members：Array<String>，成员用户ID列表
- createdAt：Timestamp

5.6.2 活动表（Activity）
- activityId：String，唯一标识
- clubId：String，所属跑团ID
- name：String，活动名称
- type：String，类型（regular/training/race/casual）
- date：String，日期（YYYY-MM-DD）
- time：String，时间（HH:MM）
- location：Object，地点（名称+坐标）
- distance：Number，距离（km）
- description：String，活动描述
- maxParticipants：Number，人数限制（可选）
- registrationDeadline：String，报名截止时间
- status：String，状态（upcoming/ongoing/completed/cancelled）
- createdAt：Timestamp

5.6.3 报名表（Registration）
- registrationId：String，唯一标识
- activityId：String，活动ID
- userId：String，报名用户ID
- note：String，备注
- registeredAt：Timestamp

5.6.4 签到表（CheckIn）
- checkInId：String，唯一标识
- activityId：String，活动ID
- userId：String，签到用户ID
- checkInTime：Timestamp，签到时间
- checkInLocation：Object，签到位置
- isManual：Boolean，是否手动补签

5.6.5 成绩表（Result）
- resultId：String，唯一标识
- activityId：String，活动ID
- userId：String，用户ID
- finishTime：String，完成时间（HH:MM:SS）
- pace：String，配速（MM:SS/km）
- source：String，数据来源（manual/health）
- createdAt：Timestamp

5.6.6 训练计划表（TrainingPlan）
- planId：String，唯一标识
- userId：String，用户ID
- name：String，计划名称
- duration：Number，周期（周）
- schedule：Array<Object>，每周安排
- targetRace：String，目标赛事（可选）
- startDate：String，开始日期
- status：String，状态（active/completed）

5.6.7 跑友名片表（RunnerCard）
- cardId：String，唯一标识
- userId：String，用户ID
- nickname：String，昵称
- runningAge：Number，跑龄（年）
- totalDistance：Number，总跑量（km）
- motto：String，个人宣言
- contactVisible：Boolean，联系方式是否可见
- createdAt：Timestamp

### 5.7 技术架构

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为跑团提供碰一碰签到+活动管理+排名统计的综合管理工具，将解决跑团组织繁琐和成员数据分散的问题，因为现有方案依赖微信群效率低。我们通过审核通过率和活动参与率来验证。

### 7.2 用户故事

7.2.1 Story 1：创建和管理活动
作为一个跑团组织者，我想创建活动并管理报名，以便高效组织跑团活动。

验收标准：
- 可填写活动名称、时间、地点、类型、距离
- 可设置人数限制和报名截止时间
- 可查看报名名单
- 可编辑和取消活动
- 可分享活动链接

7.2.2 Story 2：碰一碰签到
作为一个组织者，我想通过碰一碰让成员快速签到，以便提高签到效率。

验收标准：
- 组织者生成签到状态
- 成员手机碰触组织者设备完成签到
- 签到时间<2秒
- 显示签到成功提示
- 支持离线签到（恢复网络后同步）
- 支持组织者手动补签

7.2.3 Story 3：记录和查看成绩
作为一个跑者，我想记录跑步成绩并查看排名，以便追踪进步和获得激励。

验收标准：
- 可手动输入完成时间和配速
- 可授权同步华为运动健康数据
- 成绩自动排名
- 显示个人PB
- 查看活动成绩榜单

7.2.4 Story 4：训练计划
作为一个有目标的跑者，我想制定和跟踪训练计划，以便系统备战比赛。

验收标准：
- 可创建训练计划（周期/每周安排）
- 每日训练提醒
- 完成打卡
- 可视化进度

7.2.5 Story 5：跑团排名统计
作为一个跑团成员，我想查看跑团排名和统计，以便获得成就感和激励。

验收标准：
- 月跑量排名
- 活动参与次数排名
- 跑团总跑量统计
- TOP10榜单展示

7.2.6 Story 6：碰一碰交换名片
作为一个跑者，我想通过碰一碰认识新跑友，以便扩大跑步圈子。

验收标准：
- 碰触交换跑友名片
- 名片包含跑龄、跑量等信息
- 保存到跑友录
- 可添加备注

7.2.7 Story 7：华为账号与云同步
作为一个用户，我想我的跑团数据和个人记录自动同步，以便换手机不丢失。

验收标准：
- 华为账号一键登录
- 跑团数据、活动数据、个人记录自动同步
- 换机登录后自动恢复
- 提供账号注销功能

### 7.3 边界情况与约束

7.3.1 边界情况
- 活动人数超限：提示"报名人数已满"
- 签到时未报名：提示"请先报名活动"
- 重复签到：提示"您已签到"
- 无网络时签到：本地记录，恢复网络后同步
- 华为运动健康无数据：提示手动输入

7.3.2 技术约束
- 碰一碰NFC传输数据量限制
- 华为运动健康数据授权需用户确认
- Cloud DB免费额度需监控

9.2.1 增长风险：需要跑团组织者使用才能形成网络效应
- 概率：中
- 缓解：提供个人训练计划功能，个人跑者也能使用；提供跑团创建引导

9.2.2 审核风险：与Keep等运动App功能重叠
- 概率：中低
- 缓解：强调碰一碰签到+跑团管理+排名统计的差异化

9.2.3 技术风险：华为运动健康数据授权率低
- 概率：中
- 缓解：提供手动输入作为备选


## 10 开放问题

10.1 是否支持一人加入多个跑团？
- 倾向：支持，用户可切换当前跑团

10.2 跑团人数上限？
- 倾向：V1.0支持最多200人，满足大多数跑团需求

10.3 成绩排名是否区分性别/年龄组？
- 倾向：V1.0总排名，V1.1考虑分组排名

10.4 碰一碰签到是否支持多人同时签到？
- 倾向：支持，组织者设备可同时与多台设备碰触

12.2 用户同意前不初始化任何SDK
12.3 位置权限按需申请
12.4 健康数据授权需明确说明用途
12.5 跑团数据云端加密存储
12.6 提供账号注销功能

## 13 审核风险评估

### 13.1 低风险项

- 无UGC社区，内容可控
- 结合碰一碰、运动健康等鸿蒙特性

### 13.2 需重点关注
