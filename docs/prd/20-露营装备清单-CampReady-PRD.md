# 露营装备清单（CampReady）产品需求文档


## 1 执行摘要

我们正在为露营爱好者构建一款基于鸿蒙服务卡片的露营装备管理应用CampReady，解决露营前准备装备容易遗漏、装备管理混乱的问题。提供预设模板+智能生成+手动调整的清单创建方式，支持装备重量记录、照片、购买链接、存放位置的全方位管理，结合服务卡片倒计时提醒，成为露营爱好者的装备管家。预期上架后30天内获得400+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
22-45岁的露营爱好者，包括新手露营者和资深露营玩家，使用华为鸿蒙设备，每次露营前需要准备大量装备。

### 2.2 问题是什么
露营装备种类繁多（帐篷、睡袋、炊具、照明等几十项），每次出行前准备容易遗漏。现有方案要么是纸质清单（容易丢、不便修改），要么是通用备忘录（不够结构化），缺少一款专为露营设计的、可智能生成、可管理装备详细信息的工具。同时，装备购买后缺乏系统管理，不知道有什么、放在哪、重多少。

### 2.3 为什么这是痛点
- 遗漏风险：露营到野外才发现忘了带重要装备（如帐篷地钉、充气泵），影响体验甚至安全
- 准备耗时：每次露营前都要从头想"带什么"，重复劳动
- 管理混乱：装备分散在家各处，不知道有什么、放在哪
- 重量失控：背包露营时不清楚总重量，背到半路才发现太重
- 购买重复：不知道已经有什么，重复购买相同装备

### 2.4 证据
- 中国露营市场快速增长，露营人群超千万
- 露营装备清单是小红书/抖音热门内容，证明需求真实
- 露营新手普遍反映"不知道带什么"
- 背包露营者对装备重量敏感，需要精确计算
- 华为应用市场暂无专业的露营装备清单工具

## 5 解决方案概述

### 5.1 产品定位
CampReady是一款基于鸿蒙服务卡片的露营装备管理应用，提供预设模板+智能生成+手动调整的清单创建方式，支持装备全方位管理（重量/照片/链接/位置），结合服务卡片倒计时提醒。

### 5.2 核心用户流程

5.2.1 创建清单流程
打开App → 点击"新建清单" → 选择生成方式（模板/智能生成/空白） → 设置参数（人数/天数/季节/类型） → 生成基础清单 → 手动调整（增删改） → 保存清单

5.2.2 准备装备流程
打开清单 → 逐项勾选已准备的装备 → 查看准备进度 → 确认带齐后标记"已完成"

5.2.3 管理装备库流程
打开装备库 → 添加新装备（名称/重量/照片/链接/位置） → 查看所有装备 → 按分类/位置筛选

5.2.4 查看装备详情流程
点击装备 → 查看详细信息 → 查看购买链接 → 查看存放位置

### 5.3 功能模块

5.3.1 清单创建模块
- 创建方式选择：
  - 预设模板：精致露营模板、背包露营模板、亲子露营模板、极简露营模板（4种）
  - 智能生成：根据参数自动生成
  - 空白清单：从零开始创建
- 智能生成参数：
  - 人数（1-10人）
  - 天数（1-7天）
  - 季节（春/夏/秋/冬）
  - 露营类型（自驾/背包/房车/精致露营）
  - 是否过夜（是/否）
  - 是否做饭（是/否）
- 生成逻辑：根据参数组合从装备库中选择推荐装备
- 手动调整：
  - 添加装备（从装备库选择或新建）
  - 删除装备
  - 修改装备数量
  - 调整装备顺序
  - 添加自定义备注

5.3.2 清单管理模块
- 清单列表：按创建时间倒序展示
- 清单状态：准备中/已完成/历史
- 清单详情：
  - 装备列表（勾选/未勾选）
  - 准备进度条（百分比）
  - 预计总重量（自动计算）
  - 倒计时（距离露营日期）
- 清单操作：
  - 编辑清单
  - 复制清单（基于上次清单快速创建）
  - 删除清单
  - 分享清单（生成图片或文本）
- 清单归档：已完成的清单归档到历史

5.3.3 装备库模块
- 添加装备：
  - 名称（必填）
  - 分类（帐篷/睡袋/炊具/照明/工具/衣物/食品/其他）
  - 重量（g/kg，可选）
  - 数量（默认1）
  - 照片（最多3张）
  - 购买链接（可选）
  - 存放位置（如"客厅柜子上层""车库"）
  - 备注（可选）
- 装备列表：
  - 按分类浏览
  - 按存放位置浏览
  - 搜索装备
- 装备详情：
  - 查看完整信息
  - 查看照片
  - 点击购买链接
  - 查看存放位置
- 装备编辑：修改任何信息
- 装备删除：支持删除（二次确认，检查是否被清单引用）
- 装备统计：
  - 总装备数量
  - 总重量
  - 分类分布
  - 最近添加

5.3.4 重量管理模块
- 清单重量：自动计算清单中所有装备总重量
- 分类重量：显示各分类重量占比
- 重量预警：超过设定阈值时提示（如背包露营超过15kg）
- 轻量化建议：根据装备库推荐更轻的替代装备

5.3.5 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 清单数据、装备库数据、照片云端同步（Cloud DB + Cloud Storage）
- 支持多人共享清单（通过华为账号邀请）
- 换机后登录自动恢复
- Wi-Fi下自动同步，移动网络手动同步

5.3.6 服务卡片
- 露营倒计时卡片：显示最近一次的露营倒计时和准备进度
- 快捷清单卡片：显示当前准备中的清单，点击快速进入
- 装备提醒卡片：显示"别忘了带XX"的随机提醒
- 卡片交互：点击倒计时卡片进入清单详情，点击快捷清单进入勾选页面

### 5.4 鸿蒙特性利用清单

| 鸿蒙能力 | 应用场景 | 优先级 |
|----------|---------|--------|
| 华为账号 Account Kit | 一键登录、多人共享 | P0 |
| 云数据库 Cloud DB | 清单/装备数据同步 | P0 |

### 5.5 页面结构
- 启动页：隐私政策弹窗 → 华为账号登录
- 首页（Tab1）：最近清单 + 新建清单 + 倒计时卡片
- 清单页（Tab2）：所有清单列表 + 筛选
- 装备库（Tab3）：装备分类浏览 + 添加装备
- 统计页（Tab4）：装备统计 + 重量分析
- 我的（Tab5）：账号管理、云同步设置、模板管理、隐私政策

### 5.6 数据模型

5.6.1 清单表（Checklist）
- checklistId：String，唯一标识
- userId：String，所属用户
- name：String，清单名称
- campingDate：String，露营日期（YYYY-MM-DD）
- status：String，状态（preparing/completed/archived）
- generationType：String，生成方式（template/smart/blank）
- parameters：Object，生成参数（人数/天数/季节等）
- items：Array<Object>，装备项列表
  - itemId：String
  - gearId：String，关联装备ID
  - name：String，装备名称（快照）
  - quantity：Number，数量
  - isChecked：Boolean，是否已勾选
  - note：String，备注
- totalWeight：Number，总重量（g）
- createdAt：Timestamp
- updatedAt：Timestamp

5.6.2 装备表（Gear）
- gearId：String，唯一标识
- userId：String，所属用户
- name：String，装备名称
- category：String，分类（tent/sleeping/cooking/lighting/tools/clothing/food/other）
- weight：Number，重量（g）
- quantity：Number，数量
- photos：Array<String>，照片URL数组
- purchaseLink：String，购买链接
- storageLocation：String，存放位置
- note：String，备注
- createdAt：Timestamp
- updatedAt：Timestamp

5.6.3 清单模板表（Template）
- templateId：String，唯一标识
- name：String，模板名称
- description：String，模板描述
- category：String，类型（glamping/backpacking/family/minimal）
- defaultItems：Array<Object>，默认装备项列表
- isBuiltin：Boolean，是否系统预设

5.6.4 共享清单表（SharedChecklist）
- shareId：String，唯一标识
- checklistId：String，清单ID
- ownerId：String，所有者用户ID
- sharedWithId：String，共享给的用户ID
- permission：String，权限（view/edit）
- createdAt：Timestamp

### 5.7 技术架构

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为露营爱好者提供智能生成+手动调整+装备库管理的清单工具，将解决露营准备容易遗漏和装备管理混乱的问题，因为现有方案要么不够结构化要么无法管理装备信息。我们通过审核通过率和清单创建量来验证。

### 7.2 用户故事

7.2.1 Story 1：创建露营清单
作为一个计划露营的用户，我想快速生成一份完整的装备清单，以便不遗漏任何物品。

验收标准：
- 可选择预设模板（4种）
- 可选择智能生成（设置人数/天数/季节/类型等参数）
- 可选择空白清单
- 智能生成根据参数自动推荐装备
- 生成后可手动添加/删除/修改装备
- 可调整装备数量
- 可添加自定义备注
- 可设置露营日期

7.2.2 Story 2：准备装备逐项勾选
作为一个准备出发的露营者，我想逐项勾选已准备的装备，以便确认带齐。

验收标准：
- 清单页显示所有装备项
- 点击装备项可勾选/取消勾选
- 显示准备进度百分比
- 已勾选和未勾选分区显示
- 显示预计总重量
- 可添加装备备注
- 全部勾选后可标记清单"已完成"

7.2.3 Story 3：管理装备库
作为一个装备越来越多的露营者，我想系统管理我的所有装备，以便知道有什么、放在哪。

验收标准：
- 可添加装备（名称/分类/重量/照片/链接/位置）
- 装备分类浏览（帐篷/睡袋/炊具等）
- 按存放位置浏览
- 搜索装备
- 查看装备详情（照片/链接/位置）
- 编辑装备信息
- 删除装备（检查是否被清单引用）

7.2.4 Story 4：重量管理
作为一个背包露营者，我想知道清单总重量和各分类重量，以便控制背包重量。

验收标准：
- 自动计算清单总重量
- 显示各分类重量占比
- 可设置重量预警阈值
- 超过阈值时提示警告
- 装备库显示总重量统计

7.2.5 Story 5：多人共享清单
作为一个和朋友一起露营的用户，我想和朋友共享清单，以便分工准备。

验收标准：
- 可通过华为账号邀请好友共享清单
- 可设置共享权限（仅查看/可编辑）
- 共享好友可查看清单
- 共享好友可勾选装备（如有编辑权限）
- 实时同步勾选状态

7.2.6 Story 6：华为账号与云同步
作为一个用户，我想我的清单和装备库自动云端同步，以便换手机不丢失。

验收标准：
- 华为账号一键登录
- 清单数据自动同步
- 装备库数据自动同步
- 装备照片云端存储
- 换机登录后自动恢复
- 提供账号注销功能

7.2.7 Story 7：服务卡片
作为一个用户，我想在负一屏看到露营倒计时和准备进度，以便随时掌握准备情况。

验收标准：
- 露营倒计时卡片显示最近露营日期和倒计时天数
- 显示准备进度百分比
- 快捷清单卡片显示当前准备中的清单
- 装备提醒卡片随机提醒"别忘了带XX"
- 点击卡片进入对应页面

### 7.3 边界情况与约束

7.3.1 边界情况
- 装备被清单引用时删除：提示"该装备正在被X个清单使用，确定删除？"
- 清单日期已过：自动标记为历史，不再显示倒计时
- 重量单位切换：支持g/kg切换，自动转换
- 无网络时：本地保存，恢复网络后同步
- 共享好友无App：提示邀请下载

7.3.2 技术约束
- 装备照片占用存储空间，需压缩上传
- Cloud DB免费额度需监控
- 多人实时同步有轻微延迟（<1秒）

8.5 装备租赁功能 — 涉及交易，增加复杂度
8.6 跨设备协同（平板/智慧屏） — V1.0仅手机端
8.7 语音添加装备 — V1.1考虑


## 9 依赖与风险

### 9.1 依赖项
- 华为Account Kit接入审批
- 华为Cloud DB和Cloud Storage服务开通
- App备案

### 9.2 风险与缓解

9.2.1 审核风险：被归类为"简单清单工具"
- 概率：中低
- 缓解：强调智能生成、装备库管理、重量管理、多人共享的组合功能，突出露营垂直场景深度

9.2.2 竞争风险：与通用待办App竞争
- 概率：中
- 缓解：强调露营专用、智能生成、装备重量管理、存放位置管理的差异化

9.2.3 数据风险：装备照片占用存储
- 概率：低
- 缓解：照片压缩至单张300KB以内，监控Cloud Storage用量


## 10 开放问题

10.1 预设模板的具体装备项？
- 倾向：内置4种模板各15-20项基础装备，用户可根据实际情况调整

10.2 智能生成的推荐逻辑？
- 倾向：基于参数组合从装备库筛选推荐，如"背包+冬季"推荐羽绒睡袋而非棉睡袋

10.3 多人共享清单的冲突处理？
- 倾向：最后修改为准，显示"XX刚刚更新了清单"

10.4 装备分类的粒度？
- 倾向：8个一级分类（帐篷/睡袋/炊具/照明/工具/衣物/食品/其他），V1.1考虑二级分类

10.5 是否支持导入导出清单？
- 倾向：V1.0支持导出为文本/图片，V1.1考虑支持JSON导入导出

## 12 隐私合规设计

12.1 独立隐私政策文本，首次启动弹窗展示，用户同意后方可继续
12.2 用户同意前不初始化任何SDK
12.3 存储权限仅在上传照片场景按需申请
12.4 清单和装备数据云端加密存储
12.5 隐私政策明确说明云端数据范围、第三方SDK信息
12.6 提供账号注销功能，注销后30天内删除所有云端数据
12.7 从主界面4次以内点击可访问隐私政策
12.8 第三方SDK披露清单包含Account Kit、Cloud DB、Cloud Storage


## 13 审核风险评估

### 13.1 低风险项
- 垂直工具属性，功能明确
- 无UGC社区，无支付，无广告
- 服务卡片支持露营场景
- 多人共享是实用功能

### 13.2 需重点关注
- 与通用待办App的差异化需在描述中强调
- 多人共享功能的隐私说明

### 13.3 差异化优势
- 露营专用，智能生成算法针对露营场景优化
- 装备库全方位管理（重量/照片/链接/位置）
- 重量管理支持背包露营需求
- 多人共享清单支持团队露营分工
- 服务卡片倒计时提醒
