# 中式纹样设计工具（PatternCraft）产品需求文档


## 1 执行摘要

我们正在为传统文化爱好者、设计师、文创从业者构建一款基于鸿蒙端侧AI能力的传统纹样设计应用PatternCraft，解决用户想创作和使用中国传统及少数民族纹样但缺少专业工具的问题。提供纹样库浏览、参数化生成、自定义配色、多场景输出（壁纸/贺卡/请柬/周边预览）功能，结合服务卡片每日纹样推荐，成为鸿蒙生态文化传承品类的标杆应用。预期上架后30天内获得400+下载。


## 2 问题陈述

### 2.1 谁遇到了这个问题
三类人群：一是传统文化爱好者，想使用传统纹样装饰生活；二是设计师和文创从业者，需要传统纹样素材用于设计；三是准备中式婚礼/活动的用户，需要传统纹样制作请柬和贺卡。

### 2.2 问题是什么
中国传统纹样（云纹、回纹、缠枝纹等）和少数民族纹样（苗族蜡染、藏族唐卡、彝族刺绣等）精美但获取渠道有限。现有方案要么是图片素材网站（需付费、不可编辑），要么是专业设计软件（门槛高），缺少一款面向普通用户的、可参数化生成和自定义的纹样设计工具。

### 2.3 为什么这是痛点
- 获取难：高质量传统纹样素材分散，需多方搜集
- 编辑难：找到的图片不可编辑，无法调整颜色和密度
- 应用难：纹样不知如何应用到实际场景（壁纸、贺卡、周边）
- 认知断层：年轻一代对传统纹样了解有限，缺少学习和体验渠道

### 2.4 证据
- 国潮文化兴起，传统元素在设计和消费领域持续流行
- 故宫文创、敦煌文创等IP的成功证明传统文化商业潜力
- 匠木（榫卯结构游戏）在鸿蒙创新赛获奖，证明文化传承类应用受华为认可
- 婚礼、春节等场景对中式请柬、贺卡有稳定需求
- 华为对文化传承类应用有推荐倾斜

## 5 解决方案概述

### 5.1 产品定位
PatternCraft是一款基于鸿蒙端侧AI能力的传统纹样设计应用，提供中国传统纹样+少数民族纹样的参数化生成、自定义配色、多场景输出（壁纸/贺卡/请柬/周边预览）功能，结合纹样文化科普。

### 5.2 核心用户流程

5.2.1 浏览选择纹样流程
打开App → 首页展示纹样分类 → 选择纹样类型（如云纹） → 查看纹样详情和文化介绍 → 点击"开始设计"

5.2.2 参数化生成流程
进入设计页 → 调整参数（密度/复杂度/旋转角度等） → 选择配色方案 → 实时预览生成效果 → 满意后导出

5.2.3 多场景应用流程
生成纹样后 → 选择应用场景（壁纸/贺卡/请柬/周边预览） → 选择模板 → 调整布局 → 导出高清图

### 5.3 功能模块

5.3.1 纹样库模块
- 纹样分类：
  - 中国传统纹样：云纹、回纹、如意纹、缠枝纹、万字纹、水波纹、龙纹、凤纹、麒麟纹等（20种）
  - 少数民族纹样：
    - 苗族：蜡染图案、刺绣纹样
    - 藏族：唐卡纹样、吉祥八宝
    - 彝族：刺绣几何纹
    - 壮族：织锦纹样
    - 维吾尔族：艾德莱斯绸纹样（共15种）
- 纹样详情：
  - 高清预览图
  - 文化介绍（起源、寓意、应用场景）
  - 历史演变时间线
  - 相关纹样推荐
- 纹样搜索：按名称、寓意、应用场景搜索
- 收藏纹样：收藏喜欢的纹样到个人纹样库

5.3.2 参数化生成模块
- 基础参数（所有纹样通用）：
  - 密度：控制纹样排列疏密（稀疏/适中/密集）
  - 大小：控制单体纹样尺寸
  - 旋转：控制纹样旋转角度（0°/45°/90°/随机）
- 高级参数（因纹样而异）：
  - 云纹：卷曲度、尾部长度
  - 回纹：转角样式（直角/圆角）
  - 缠枝纹：枝条弯曲度、花朵密度
  - 蜡染：冰裂纹强度、图案清晰度
- 实时预览：参数调整后即时渲染预览
- 随机生成：一键随机参数生成新效果

5.3.3 配色方案模块
- 预设配色：
  - 传统配色：故宫红墙金瓦、青花蓝白、敦煌重彩、水墨黑白等（10套）
  - 现代配色：莫兰迪色系、马卡龙色系、渐变色系等（5套）
  - 节日配色：春节红金、中秋黄橙、婚礼红金等（5套）
- 自定义配色：
  - 主色/辅色/点缀色独立选择
  - 色轮取色
  - 保存自定义配色方案（最多10套）
- 配色预览：实时预览配色效果

5.3.4 多场景输出模块
- 壁纸输出：
  - 尺寸：按设备屏幕自适应（1080x2400等）
  - 布局：平铺/居中/渐变过渡
  - 导出：高清PNG
- 贺卡输出：
  - 尺寸：标准贺卡比例（可打印）
  - 模板：春节/中秋/生日/通用（10种）
  - 可添加文字祝福语
  - 导出：高清PNG/PDF
- 请柬输出：
  - 尺寸：标准请柬比例
  - 模板：中式婚礼/传统满月/寿宴/乔迁（8种）
  - 可添加文字（新人姓名、日期、地点）
  - 导出：高清PNG/PDF
- 周边预览：
  - 预览模板：手机壳/丝巾/帆布袋/T恤/马克杯（5种）
  - 3D预览：模拟纹样在实物上的效果
  - 导出：预览图（用于定制参考）

5.3.5 我的作品模块
- 作品列表：按创建时间倒序展示
- 作品详情：查看大图、重新编辑、导出
- 作品分类：按应用场景分类（壁纸/贺卡/请柬）
- 作品删除：支持删除
- 云端同步：作品数据通过Cloud DB同步，图片通过Cloud Storage存储

5.3.6 纹样科普模块
- 纹样百科：按分类浏览所有纹样的文化介绍
- 每日纹样：每天推送一个纹样及其文化故事
- 纹样对比：对比不同朝代/民族的相似纹样演变
- 应用场景指南：介绍不同纹样适合的使用场景

5.3.7 华为账号与云同步
- 华为账号一键登录（Account Kit）
- 作品、收藏纹样、自定义配色方案云端同步
- 换机后登录自动恢复
- Wi-Fi下自动同步，移动网络手动同步

5.3.8 服务卡片
- 每日纹样卡片：负一屏展示今日推荐纹样缩略图和名称
- 快捷设计卡片：一键进入最近使用的纹样设计页
- 卡片交互：点击每日纹样进入纹样详情，点击快捷设计进入设计页

### 5.5 页面结构
- 启动页：隐私政策弹窗 → 华为账号登录
- 首页（Tab1）：纹样分类入口 + 每日纹样 + 最近使用
- 纹样库（Tab2）：分类浏览 + 搜索 + 收藏
- 设计页：参数调节 + 配色选择 + 实时预览
- 输出页：场景选择 + 模板选择 + 最终导出
- 我的作品（Tab3）：作品列表 + 分类筛选
- 纹样百科（Tab4）：文化介绍 + 每日纹样
- 我的（Tab5）：账号管理、云同步设置、自定义配色、隐私政策

### 5.6 数据模型

5.6.1 纹样表（Pattern）
- patternId：String，唯一标识
- name：String，纹样名称
- category：String，分类（chinese-traditional/miao/tibetan/yi/zhuang/uyghur）
- subCategory：String，子分类
- previewUrl：String，预览图URL
- description：String，文化介绍
- origin：String，起源
- meaning：String，寓意
- history：String，历史演变
- usageScenarios：Array<String>，适用场景
- parameters：Object，可调整参数定义
- isBuiltin：Boolean，是否系统预设

5.6.2 作品表（Artwork）
- artworkId：String，唯一标识
- userId：String，所属用户
- patternId：String，使用的纹样ID
- patternParams：Object，纹样参数值
- colorScheme：Object，配色方案
- sceneType：String，应用场景（wallpaper/card/invitation/preview）
- sceneTemplate：String，场景模板ID
- customText：String，自定义文字（贺卡/请柬）
- outputImageUrl：String，输出图片URL
- createdAt：Timestamp
- updatedAt：Timestamp

5.6.3 自定义配色表（CustomColor）
- colorId：String，唯一标识
- userId：String，所属用户
- name：String，配色方案名称
- primaryColor：String，主色
- secondaryColor：String，辅色
- accentColor：String，点缀色
- createdAt：Timestamp

5.6.4 收藏纹样表（FavoritePattern）
- favoriteId：String，唯一标识
- userId：String，所属用户
- patternId：String，纹样ID
- createdAt：Timestamp

### 5.7 技术架构

## 7 用户故事与需求

### 7.1 Epic假设
我们认为，为传统文化爱好者提供参数化生成+自定义配色+多场景输出的传统纹样设计工具，将解决高质量纹样素材难获取和应用难的问题，因为现有方案要么不可编辑要么门槛太高。我们通过审核通过率和纹样生成量来验证。

### 7.2 用户故事

7.2.1 Story 1：浏览和选择纹样
作为一个传统文化爱好者，我想浏览不同类型的传统纹样并了解文化背景，以便选择适合的纹样进行设计。

验收标准：
- 提供至少35种纹样（20种中国传统+15种少数民族）
- 每个纹样有高清预览图
- 每个纹样有文化介绍（起源、寓意、历史）
- 支持按分类浏览和搜索
- 支持收藏喜欢的纹样
- 纹样详情页有相关纹样推荐

7.2.2 Story 2：参数化生成纹样
作为一个想自定义纹样的用户，我想调整纹样参数和配色，以便生成专属的设计效果。

验收标准：
- 提供密度、大小、旋转等基础参数
- 不同纹样有专属高级参数
- 提供至少20套预设配色方案
- 支持自定义配色（主/辅/点缀色）
- 参数调整后实时预览生成效果
- 支持一键随机生成
- 支持保存自定义配色方案

7.2.3 Story 3：多场景输出应用
作为一个想将纹样应用到实际场景的用户，我想选择壁纸/贺卡/请柬/周边预览等场景，以便生成可用的设计图。

验收标准：
- 支持壁纸输出（自适应屏幕尺寸）
- 支持贺卡输出（10种模板，可添加祝福语）
- 支持请柬输出（8种模板，可添加文字信息）
- 支持周边预览（5种实物模板）
- 贺卡/请柬支持导出PDF格式（便于打印）
- 所有场景支持高清导出

7.2.4 Story 4：纹样文化科普
作为一个想了解传统文化的用户，我想阅读纹样背后的文化故事，以便更好地理解和使用纹样。

验收标准：
- 提供纹样百科，按分类浏览所有纹样介绍
- 每日推送一个纹样及其文化故事（服务卡片同步）
- 提供纹样对比功能（不同朝代/民族的演变）
- 提供应用场景指南

7.2.5 Story 5：管理我的作品
作为一个有多个作品的用户，我想查看和管理我的设计作品，以便回顾和重新编辑。

验收标准：
- 作品列表按时间倒序展示
- 支持按应用场景分类筛选
- 可查看作品大图
- 可重新进入编辑模式修改
- 可删除作品
- 所有作品自动云端同步

7.2.6 Story 6：华为账号与云同步
作为一个用户，我想我的作品和收藏自动云端同步，以便换手机后不丢失。

验收标准：
- 华为账号一键登录
- 作品、收藏纹样、自定义配色方案自动同步
- 换机登录后自动恢复
- 提供账号注销功能

7.2.7 Story 7：服务卡片
作为一个用户，我想在负一屏看到每日推荐纹样，以便获取灵感和了解文化。

验收标准：
- 每日纹样卡片展示今日推荐纹样缩略图和名称
- 快捷设计卡片一键进入最近使用的纹样设计页
- 点击卡片进入对应页面

### 7.3 边界情况与约束

7.3.1 边界情况
- 纹样生成复杂度过高：提示"参数过于复杂，建议降低密度"
- 配色对比度不足：提示"当前配色对比度较低，可能影响视觉效果"
- 导出图片过大：自动压缩至合理大小（壁纸<2MB，贺卡/请柬<5MB）
- 自定义文字过长：限制字数（贺卡50字，请柬100字）
- 无网络时：本地缓存纹样库，支持离线生成和保存，恢复网络后同步

7.3.2 技术约束
- 复杂纹样参数化生成依赖Canvas性能，低端设备可能卡顿
- 纹样库内置在App中，增加包体大小（预计50-100MB）
- 高清纹样图片占用存储空间
- Cloud DB免费额度需监控


## 8 范围外（不在V1.0中构建）

8.1 用户上传自定义纹样 — 避免UGC审核复杂度，V1.0仅使用内置纹样
8.2 纹样交易/商城 — 涉及电商和支付，V1.0保持纯净
8.3 社交分享功能（作品广场） — 避免UGC社区审核
8.4 动画/动态纹样 — 增加开发量和性能要求
8.5 3D纹样效果 — 技术复杂度高
8.6 跨设备协同（平板/智慧屏设计） — V1.0仅手机端
8.7 意图框架场景推荐 — P2优先级，先上架后迭代


## 9 依赖与风险

### 9.1 依赖项
- 华为Account Kit接入审批
- 华为Cloud DB和Cloud Storage服务开通
- Core Vision Kit端侧AI能力确认
- 纹样图片素材准备（需确认版权或原创绘制）
- App备案

### 9.2 风险与缓解

9.2.1 内容风险：纹样图片版权问题
- 概率：中
- 缓解：优先使用公有领域纹样或原创绘制；在版权说明中注明来源

9.2.2 审核风险：被归类为"简单壁纸工具"
- 概率：中低
- 缓解：强调参数化生成和文化科普功能，突出与静态壁纸App的差异化

9.2.3 技术风险：复杂纹样生成性能不足
- 概率：中（低端设备）
- 缓解：提供性能模式选项（降低渲染精度）；复杂纹样简化参数范围

9.2.4 包体风险：纹样库导致App过大
- 概率：中
- 缓解：纹样图片使用WebP格式压缩；考虑按需下载部分纹样（V1.1）


## 10 开放问题

10.1 纹样图片数据来源？
- 倾向：公有领域博物馆藏品（故宫、国博开放资源）+ 原创绘制

10.2 是否支持纹样组合（多个纹样叠加）？
- 倾向：V1.0不支持，保持单纹样设计；V1.1考虑支持双层叠加

10.3 贺卡/请柬模板的数量？
- 倾向：V1.0提供10种贺卡模板+8种请柬模板，后续增量添加

10.4 周边预览的3D效果如何呈现？
- 倾向：V1.0使用2D贴图模拟3D效果（平面展开图），V1.1考虑真3D预览

10.5 是否支持导出矢量格式（SVG）？
- 倾向：V1.0仅支持PNG/PDF，SVG导出留到V1.1（涉及矢量渲染）
