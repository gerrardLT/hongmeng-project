第三方 SDK 目录

MamaTrack 孕期体重曲线管理

为保障 MamaTrack 相关功能的实现与应用的稳定运行，我们可能会接入由第三方提供的软件开发包（SDK）。我们会对 SDK 进行严格的安全监测，并要求合作伙伴采取严格的数据保护措施。以下为 MamaTrack 接入的第三方 SDK 目录及相关信息。

H
华为 Account Kit
提供商：华为软件技术有限公司
使用目的
提供华为账号一键登录功能，简化用户登录流程。
收集的数据类型
  • 设备标识信息（AAID）
  • 华为账号 OpenID
  • 设备型号与系统版本
隐私政策链接
https://developer.huawei.com/consumer/cn/doc/development/HMSCore-Guides/sdk-data-security-0000001050050869
C
华为 Cloud DB
提供商：华为软件技术有限公司
使用目的
提供数据云同步服务，确保用户在不同设备间的数据一致性。
收集的数据类型
  • 用户主动同步的健康数据（体重、身高、预产期、产检记录等）
  • 设备标识信息
  • 应用版本号
隐私政策链接
https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-clouddb-introduction-0000001059214589
S
华为 Cloud Storage
提供商：华为软件技术有限公司
使用目的
提供孕期照片的云存储备份服务。
收集的数据类型
  • 用户主动上传的照片文件
  • 照片上传时间戳
  • 设备标识信息
隐私政策链接
https://developer.huawei.com/consumer/cn/doc/development/AppGallery-connect-Guides/agc-cloudstorage-introduction-0000001054840119
H
华为运动健康
提供商：华为软件技术有限公司
使用目的
用于体重数据的双向同步，可将智能秤等设备的体重数据同步至 MamaTrack。
收集的数据类型
  • 体重数据（需用户单独授权）
  • 数据同步时间戳
  • 设备标识信息
隐私政策链接
https://consumer.huawei.com/cn/privacy/health-privacy-statement/

特别提示：以上 SDK 仅在您使用对应功能时才会被调用，我们不会未经您同意收集您的个人信息。您可以在系统设置中撤回对特定 SDK 的授权，撤回授权可能会影响相应功能的正常使用。
