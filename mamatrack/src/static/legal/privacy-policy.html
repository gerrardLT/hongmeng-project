MamaTrack 隐私政策

孕期体重曲线管理

引言：MamaTrack（以下简称"本应用"）深知个人信息对您的重要性，我们会尽力保护您的个人信息安全。我们致力于维持您对我们的信任，恪守以下原则保护您的个人信息：权责一致原则、目的明确原则、选择同意原则、最小必要原则、确保安全原则、主体参与原则、公开透明原则等。同时，我们承诺，我们将按业界成熟的安全标准，采取相应的安全保护措施来保护您的个人信息。

一、我们收集哪些信息

为了向您提供孕期体重管理服务，我们可能需要收集和使用您的以下信息：

  • 基础身体数据：身高、孕前体重、当前体重等，用于计算BMI和推荐增重范围。
  • 预产期信息：您提供的预产期日期，用于计算孕周和展示阶段性建议。
  • 孕期照片：您主动上传的孕期拍照记录，用于生成孕期时光轴和照片对比。
  • 产检数据：血压、宫高、腹围、胎心率等产检记录，用于辅助追踪孕期健康。
  • 设备信息：设备型号、操作系统版本，用于优化应用兼容性和排查问题。
  • 通知权限：用于发送称重提醒和产检提醒。

二、健康数据的用途说明

您提供的身高、体重、产检等健康数据仅用于以下目的：

  • 计算BMI指数及孕期推荐增重范围
  • 生成个人体重变化曲线和统计报告
  • 提供基于孕周的阶段性健康提示
  • 在您授权的情况下，同步至华为运动健康

重要提示：本应用提供的所有数据分析和建议仅供参考，不构成医疗诊断或医疗建议。如有任何健康疑问或异常，请务必及时咨询专业医生。

三、数据存储与安全

3.1 本地存储

您的核心健康数据默认保存在本地设备中，采用加密存储方式。即使设备丢失，他人也无法直接读取您的原始健康数据。

3.2 云端同步（可选）

您可以选择开启云端同步功能，将数据备份至华为云。开启后，您的数据将通过加密通道传输并存储。您可随时在设置中关闭云端同步。

3.3 安全措施

  • 数据传输采用 HTTPS/TLS 加密
  • 敏感字段进行本地加密存储
  • 定期安全审计和漏洞修复

四、家人共享功能

本应用支持家人共享功能，您可以通过邀请码邀请家人查看您的孕期数据。在共享过程中：

  • 仅共享您授权的数据范围
  • 家人无法修改或删除您的原始数据
  • 您可随时撤销共享权限
  • 邀请码有效期为7天，过期自动失效

五、第三方 SDK 说明

为了提供更完善的服务，本应用集成了以下第三方 SDK：

  • 华为 Account Kit：用于华为账号登录认证，收集设备标识、华为账号信息。
  • 华为 Cloud DB：用于数据云同步，收集您主动同步的健康数据。
  • 华为 Cloud Storage：用于孕期照片云备份，收集您上传的照片文件。
  • 华为运动健康：用于体重数据同步，需您单独授权。

详细的第三方 SDK 列表及数据收集说明，请查看《第三方 SDK 目录》。

六、您的权利

根据相关法律法规，您对个人信息享有以下权利：

  • 查看权：您可以随时查看应用内记录的所有个人数据。
  • 修改权：您可以修改身高、体重、预产期等个人信息。
  • 删除权：您可以删除单条体重记录、照片或全部数据。
  • 导出权：您可以将体重记录导出为数据文件。
  • 撤回同意：您可以撤回隐私政策授权，撤回后我们将停止使用并删除您的数据。

七、账号注销

您可以通过以下流程注销账号：

  • 进入"我的" → "设置" → "账号与安全" → "注销账号"
  • 确认注销后，我们将删除您的云端数据
  • 本地数据将在应用卸载后清除
  • 注销后，您的邀请码将失效，家人共享关系自动解除
  • 注销操作不可逆转，请谨慎操作

八、儿童隐私保护

本应用主要面向成年准妈妈用户。我们不会故意收集未满14周岁儿童的个人信息。如果您发现我们意外收集了儿童信息，请立即联系我们删除。

九、政策更新

我们可能会不时更新本隐私政策。如隐私政策发生变更，我们将在应用内以弹窗或通知的形式告知您。变更后的隐私政策在公示期满后生效。

十、联系我们

如果您对本隐私政策有任何疑问、意见或建议，请通过以下方式与我们联系：

  • 应用内反馈：我的 → 设置 → 意见反馈
  • 电子邮箱：support@mamatrack.app
  • 我们会在收到您的反馈后15个工作日内予以回复。
