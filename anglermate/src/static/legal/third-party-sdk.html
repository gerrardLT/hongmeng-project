第三方 SDK 目录

版本日期：2026年4月

为了向您提供完善的功能服务，AnglerMate 钓鱼天气钓点记录应用集成了以下第三方 SDK。我们在此列明各 SDK 的名称、功能说明、收集的信息类型及其隐私政策链接，以便您了解相关信息的处理方式。

SDK 详细信息

SDK 名称 功能说明 收集的信息类型 隐私政策链接
华为 Account Kit 用户登录认证 华为账号信息、设备标识符 developer.huawei.com
华为 Cloud DB 云端数据存储与同步 钓点数据、渔获记录、提醒设置 developer.huawei.com
华为 Cloud Storage 照片云端存储 照片文件、文件元数据 developer.huawei.com
华为 Map Kit 地图显示与导航 设备位置信息 developer.huawei.com
华为 Intent Kit 意图框架与智能提醒 位置信息、提醒规则配置 developer.huawei.com
和风天气 API 天气数据查询服务 设备位置信息（经纬度） qweather.com
说明：上述第三方 SDK 仅在实现其所述功能时收集必要的信息。我们已与各 SDK 提供方签署数据处理协议，确保其按照适用法律法规处理您的个人信息。如您希望了解更多关于各 SDK 的数据处理详情，请访问上述隐私政策链接或通过 support@anglermate.com 联系我们。
