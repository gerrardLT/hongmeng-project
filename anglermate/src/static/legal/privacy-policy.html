AnglerMate 隐私政策

版本日期：2026年4月

一、引言

欢迎您使用 AnglerMate 钓鱼天气钓点记录（以下简称"本应用"）。本应用是一款面向钓鱼爱好者的综合工具，提供钓鱼天气查询、潮汐月相信息、钓点管理、渔获记录及数据统计等功能。我们高度重视您的个人信息和隐私保护。本政策将帮助您了解我们如何收集、使用、存储和保护您的个人信息。请您在使用本应用前仔细阅读并理解本政策。

二、信息收集与使用

为向您提供本应用的核心功能，我们可能收集以下个人信息：

信息类型 用途说明 必要性
位置信息 用于记录钓点位置、获取当地天气与潮汐数据、在地图上展示钓点 核心功能必需
照片数据 用于钓点环境记录和渔获拍照记录，丰富您的钓鱼日志 可选功能
账号信息 通过华为账号登录认证，实现数据云同步和多设备访问 云同步功能必需
设备信息 用于应用适配优化、问题诊断和版本兼容性处理 基础运行必需

三、数据存储与安全

我们采取多重措施保障您的数据安全：

  • Cloud DB 加密：同步至华为 Cloud DB 的数据（钓点、渔获记录等）均采用加密传输和加密存储，确保云端数据安全
  • Cloud Storage 云端加密：上传至华为 Cloud Storage 的照片文件采用服务端加密存储，传输过程使用 TLS/SSL 加密
  • 本地缓存：应用在设备本地缓存部分数据以提升使用体验，本地敏感数据采用 AES-256 加密存储
  • 数据最小化：我们仅收集实现功能所必需的最少数据，并在达到目的后及时删除或匿名化
  • 访问控制：采取严格的访问控制和日志审计措施，防止数据泄露、篡改或丢失

和风天气 API 和风天气 天气数据、潮汐月相信息查询

五、数据共享

重要声明：我们不会出售、出租或以其他商业方式向第三方提供您的个人数据。除以下情形外，我们不会向任何第三方共享您的个人信息：
  • 获得您的明确授权同意
  • 根据法律法规、诉讼争议解决需要，或行政、司法机关依法提出的要求
  • 为实现本政策所述功能，与上述第三方服务提供方共享必要信息

六、用户权利

根据相关法律法规，您对自己的个人信息享有以下权利：

  • 查看权：您可以随时在应用内查看您的钓点记录、渔获数据等个人信息
  • 导出权：您有权导出您的个人数据副本，包括钓点、渔获记录及统计数据
  • 删除权：您可以删除单条或全部数据记录，也可要求我们删除服务器端的数据
  • 注销权：您可以在应用内申请注销账号，注销后我们将在 30 个工作日内删除您的所有个人数据

行使上述权利，请通过本政策末尾的联系方式与我们取得联系。

七、未成年人保护

本应用主要面向年满 18 周岁的成年人。如果您是未满 18 周岁的未成年人，请在监护人指导下使用本应用，并确保监护人已阅读并同意本隐私政策。我们不会主动识别未成年人的身份，但建议监护人关注未成年人的应用使用情况。钓鱼活动涉及户外安全，未成年人须在成年人陪同下进行。

八、政策更新

我们可能会不时修订本隐私政策。更新后的政策将在应用内显著位置公布，并注明最新修订日期。如您在本政策更新后继续使用本应用，即视为您已阅读并接受修订后的政策。重大变更我们将通过应用内通知或弹窗方式提醒您。
