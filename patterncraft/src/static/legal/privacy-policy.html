PatternCraft 隐私政策

生效日期：2025年1月1日

导语

欢迎您使用 PatternCraft 中式纹样设计工具（以下简称"本应用"）。我们高度重视您的个人信息和隐私保护。本政策将帮助您了解我们如何收集、使用、存储和保护您的个人信息。请您在使用本应用前仔细阅读并理解本政策。

一、收集的个人信息

为向您提供本应用的核心功能，我们可能收集以下个人信息：

信息类型 用途说明 存储位置 删除方式
华为账号ID / 手机号 登录认证、账号管理、数据同步 本地存储 + 华为 Cloud DB 注销账号后删除
存储权限 保存纹样设计作品、导出图片文件 本地存储 卸载应用后清除
网络权限 登录验证、云端数据同步、素材库获取 仅在必要最小范围内使用 断开网络即停止传输

二、不收集的信息

本应用明确不收集以下类型的信息：

  • 精确或粗略地理位置信息
  • 手机联系人、通讯录
  • 通话记录、短信内容
  • 相机或麦克风数据
  • 财务信息、支付记录
  • 设备上的其他应用使用数据

三、信息使用目的

我们仅将收集的信息用于以下目的：

  1. 核心功能：提供中式纹样参数化设计、配色方案生成、多场景输出等核心服务
  2. 账号管理：维护您的登录状态，保障账号安全
  3. 数据同步：将您的设计作品与设置在云端安全备份与同步
  4. 服务改进：基于匿名化统计数据优化产品体验
重要声明：我们不会将您的个人信息用于广告推送、用户画像构建或任何与核心功能无关的商业目的。未经您的明确同意，我们不会向任何第三方共享您的可识别个人信息。

四、第三方 SDK

本应用集成以下第三方 SDK，以提供必要的账号与数据服务：

SDK 名称 提供方 用途 收集信息
Account Kit（华为认证 SDK） 华为软件技术有限公司 华为账号一键登录 华为账号ID、UnionID
Cloud DB SDK 华为软件技术有限公司 云端数据同步与备份 用户设计作品、应用设置（经加密）
Cloud Storage SDK 华为软件技术有限公司 纹样素材与作品图片存储 用户上传的设计文件（经加密）

五、数据存储与安全

  • 存储位置：您的个人数据主要存储于设备本地；同步数据存储于华为 Cloud DB 中国区服务器
  • 加密措施：敏感数据在传输过程中采用 TLS/SSL 加密；本地关键数据采用 AES-256 加密存储
  • 安全措施：我们采取技术和管理措施防止数据泄露、篡改或丢失，包括访问控制、日志审计、定期安全评估
  • 数据最小化：我们仅收集实现功能所必需的最少数据，并在达到目的后及时删除或匿名化

六、数据保存期限

数据类型 保存期限 到期处理方式
账号认证信息 账号存续期间 注销账号后 30 天内彻底删除
设计作品数据 用户自行管理期间 用户删除或注销账号后清除
应用设置 账号存续期间 注销账号后清除
日志与调试信息 最多 90 天 自动匿名化删除

七、您的权利

根据相关法律法规，您对自己的个人信息享有以下权利：

  • 知情权：您有权了解我们如何处理您的个人信息
  • 访问权：您可以随时查看我们持有的关于您的个人信息
  • 更正权：您可以更正不准确或不完整的个人信息
  • 删除权：您可以要求我们删除您的个人信息（法律法规另有规定除外）
  • 撤回同意：您可以随时撤回对个人信息处理的同意，撤回后不影响此前基于同意进行的处理
  • 数据导出：您有权获取您的个人数据副本（结构化、通用格式）

行使上述权利，请通过本政策末尾的联系方式与我们取得联系。

八、未成年人保护

本应用主要面向年满 18 周岁的成年人。如果您是未满 18 周岁的未成年人，请在监护人指导下使用本应用，并确保监护人已阅读并同意本隐私政策。我们不会主动识别未成年人的身份，但建议监护人关注未成年人的应用使用情况。

九、政策更新

我们可能会不时修订本隐私政策。更新后的政策将在应用内显著位置公布，并注明最新修订日期。如您在本政策更新后继续使用本应用，即视为您已阅读并接受修订后的政策。重大变更我们将通过应用内通知或弹窗方式提醒您。

十、联系方式

如您对本隐私政策有任何疑问、意见或建议，或希望行使您的个人信息权利，请通过以下方式联系我们：

电子邮箱：privacy@patterncraft.app

反馈入口：应用内【我的】→【设置】→【意见反馈】

我们将在收到您的请求后 15 个工作日内予以回复。
