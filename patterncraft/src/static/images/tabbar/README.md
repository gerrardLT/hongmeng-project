# TabBar 图标文件清单

本目录需要放入以下 TabBar 图标文件：

| 文件名 | 说明 |
|--------|------|
| home.png | 首页（默认状态） |
| home-active.png | 首页（选中状态） |
| library.png | 纹样库（默认状态） |
| library-active.png | 纹样库（选中状态） |
| works.png | 我的作品（默认状态） |
| works-active.png | 我的作品（选中状态） |
| encyclopedia.png | 百科（默认状态） |
| encyclopedia-active.png | 百科（选中状态） |
| profile.png | 我的（默认状态） |
| profile-active.png | 我的（选中状态） |

## 图标规格

- **尺寸**: 81 × 81 px
- **格式**: PNG（透明背景）
- **默认状态**: 灰色调 #999999
- **选中状态（active）**: 故宫红色调 #C41A16
