第三方 SDK 目录

版本日期：2026年4月27日

为了向您提供完善的功能服务，RunClub 跑团活动管理应用集成了以下第三方 SDK。我们在此列明各 SDK 的名称、提供方、功能说明、收集的信息类型、数据使用目的、数据安全措施及隐私政策链接，以便您了解相关信息的处理方式。

SDK 详细信息

SDK 名称 提供方公司 功能说明 收集的信息类型 数据使用目的 数据安全措施 隐私政策链接
华为 Account Kit 华为技术有限公司 用户登录认证 华为账号信息、设备标识符 用于用户身份验证与授权登录，实现账号体系的统一管理 TLS/SSL 加密传输，OAuth 2.0 授权协议，服务端加密存储 查看隐私政策
华为 Cloud DB 华为技术有限公司 云端数据存储与同步 活动记录、训练计划、跑步记录、用户设置 实现活动数据、训练计划、跑步记录等用户数据的云端存储与多设备同步 TLS 1.2+ 加密传输，服务端 AES-256 加密存储，访问控制与审计 查看隐私政策
华为 Share Kit 华为技术有限公司 碰一碰签到与名片交换 NFC 传输数据、设备标识符、位置信息 实现活动现场 NFC 碰一碰签到和跑友名片快速交换功能 NFC 近场通信加密，数据签名验证，防篡改保护 查看隐私政策
华为运动健康 Kit 华为技术有限公司 跑步运动数据同步 跑步距离、配速、用时、卡路里、心率等运动数据 从华为运动健康应用同步用户的跑步记录，实现运动数据自动导入 TLS/SSL 加密传输，用户授权访问控制，数据脱敏处理 查看隐私政策

SDK 数据保留与跨境处理说明

SDK 名称 数据保留期限 是否涉及跨境 数据传输地
华为 Account Kit 注销后 30 天内删除 是 中国大陆、中国香港
华为 Cloud DB 注销后 30 天内删除 是 中国大陆
华为 Share Kit NFC 数据为即时传输，不长期存储；本地缓存 7 天后自动清理 否 设备间近场传输，不经过云端
华为运动健康 Kit 同步后数据存储在 Cloud DB 中，按 Cloud DB 保留策略执行 是 中国大陆、中国香港

关于第三方 SDK 的用户权利

针对上述第三方 SDK 收集和处理的个人信息，您享有以下权利：

  • 查看权：您有权了解各 SDK 收集了哪些个人信息，并可通过各 SDK 提供方的隐私政策链接查阅详细的数据处理说明
  • 删除权：您可以通过注销账号或联系我们的方式，要求删除第三方 SDK 所存储的与您相关的个人信息
  • 投诉权：如您认为第三方 SDK 对您个人信息的处理存在不当行为，您有权向相关监管部门进行投诉举报，或通过本应用联系方式向我们反映
  • 撤回权：您可以随时通过关闭相关权限或禁用云同步等方式，撤回对第三方 SDK 收集个人信息的同意。撤回后，相关 SDK 将停止收集对应信息
说明：
  • 上述第三方 SDK 仅在实现其所述功能时收集必要的信息，严格遵循最小必要原则
  • 我们已与各 SDK 提供方签署数据处理协议（DPA），确保其按照适用法律法规处理您的个人信息
  • 第三方 SDK 的数据收集均需获得用户的明确知情同意方可进行
  • 本第三方 SDK 目录将每 6 个月进行审查和更新，以反映最新的 SDK 集成情况
  • 如您希望了解更多关于各 SDK 的数据处理详情，请访问上述隐私政策链接或通过 support@runclub.com 联系我们
