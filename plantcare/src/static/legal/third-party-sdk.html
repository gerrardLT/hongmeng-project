第三方 SDK 目录

关于第三方 SDK 的用户权利

针对上述第三方 SDK 收集和处理的个人信息，您享有以下权利：

  • 查看权：您有权了解各 SDK 收集了哪些个人信息，并可通过各 SDK 提供方的隐私政策链接查阅详细的数据处理说明
  • 删除权：您可以通过注销账号或联系我们的方式，要求删除第三方 SDK 所存储的与您相关的个人信息
  • 投诉权：如您认为第三方 SDK 对您个人信息的处理存在不当行为，您有权向相关监管部门进行投诉举报，或通过本应用联系方式向我们反映
  • 撤回权：您可以随时通过关闭相关权限或禁用云同步等方式，撤回对第三方 SDK 收集个人信息的同意。撤回后，相关 SDK 将停止收集对应信息
说明：
  • 上述第三方 SDK 仅在实现其所述功能时收集必要的信息，严格遵循最小必要原则
  • 我们已与各 SDK 提供方签署数据处理协议（DPA），确保其按照适用法律法规处理您的个人信息
  • 第三方 SDK 的数据收集均需获得用户的明确知情同意方可进行
  • 本第三方 SDK 目录将每 6 个月进行审查和更新，以反映最新的 SDK 集成情况
  • 如您希望了解更多关于各 SDK 的数据处理详情，请访问上述隐私政策链接或通过 support@plantcare.com 联系我们
