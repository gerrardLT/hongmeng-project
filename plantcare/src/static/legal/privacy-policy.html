PlantCare 隐私政策

版本日期：2026年4月27日  |  生效日期：2026年4月27日

一、引言

欢迎您使用 PlantCare 养花浇水提醒（以下简称"本应用"）。本应用是一款面向植物爱好者的智能养护管理工具，提供植物管理、智能浇水施肥提醒、植物百科、生长记录、养护统计等功能。我们高度重视您的个人信息和隐私保护。本政策将帮助您了解我们如何收集、使用、存储和保护您的个人信息。请您在使用本应用前仔细阅读并理解本政策。

二、法律依据与规范

本隐私政策依据以下中华人民共和国法律法规及规范性文件制定：

  • 《中华人民共和国个人信息保护法》
  • 《中华人民共和国网络安全法》
  • 《移动互联网应用程序个人信息保护管理暂行规定》
  • 《关于规范移动互联网应用个人信息收集使用的通知》

我们承诺在个人信息处理活动中严格遵循"合法、正当、必要"原则，仅在具有明确、合理目的的情况下收集和处理您的个人信息，并采取对个人权益影响最小的方式进行处理。

三、信息收集与使用

为向您提供本应用的核心功能，我们可能收集以下个人信息：

信息类型 用途说明 收集方式 必要性
植物照片 展示植物外观、生成生长对比记录 用户拍照上传或从相册选择 核心功能必需
位置信息 获取当地天气数据，用于智能调整浇水提醒频率 用户授予位置权限后获取，可随时在系统设置中关闭 可选
账号信息 通过华为账号登录认证，实现数据云同步和多设备访问 用户主动选择华为账号登录时由华为 Account Kit 提供 云同步功能必需
植物数据 记录用户的植物信息，包括植物名称、品种、种植日期、养护周期等 用户主动录入 核心功能必需
养护记录 记录浇水、施肥、修剪、换盆等养护行为及时间 用户手动记录或系统根据提醒自动生成 核心功能必需
设备信息 用于应用适配优化、问题诊断和版本兼容性处理 应用运行时自动采集（设备型号、系统版本等） 基础运行必需

四、数据存储与安全

我们采取多重措施保障您的数据安全：

  • Cloud DB 加密：同步至华为 Cloud DB 的数据（植物信息、养护记录等）均采用加密传输和加密存储，确保云端数据安全
  • Cloud Storage 安全：用户上传的植物照片通过华为 Cloud Storage 加密传输并安全存储
  • 本地缓存：应用在设备本地缓存部分数据以提升使用体验，本地敏感数据采用 AES-256 加密存储
  • 数据最小化：我们仅收集实现功能所必需的最少数据，并在达到目的后及时删除或匿名化
  • 访问控制：采取严格的访问控制和日志审计措施，防止数据泄露、篡改或丢失

4.1 数据保留期限

数据类型 保留期限
植物信息、养护记录、生长照片 用户主动删除或注销账号前持续保存；注销后 30 个工作日内删除
登录日志、访问日志 90 天后自动删除
设备信息、日志信息 30 天后自动删除或匿名化处理

4.2 数据跨境处理

本应用使用华为 Cloud DB 和 Cloud Storage 服务进行云端数据存储。相关服务器部署在中国大陆及中国香港等区域。

  • 所有数据传输均采用 TLS 1.2+ 协议加密，确保传输过程的安全性
  • 用户启用云同步功能即视为知悉并同意相关数据的跨境处理
  • 您可以随时在应用设置中禁用云同步，选择本地存储模式以停止数据跨境传输
  • 中国大陆用户的数据原则上存储在中国大陆境内

六、数据共享

重要声明：我们不会出售、出租或以其他商业方式向第三方提供您的个人数据。除以下情形外，我们不会向任何第三方共享您的个人信息：
  • 获得您的明确授权同意
  • 根据法律法规、诉讼争议解决需要，或行政、司法机关依法提出的要求
  • 为实现本政策所述功能，与上述第三方服务提供方共享必要信息

七、用户权利

根据相关法律法规，您对自己的个人信息享有以下权利：

  • 查看权：您可以随时在应用内查看您的植物信息、养护记录、生长照片等个人信息
  • 修改权：您有权随时修改您的个人资料、植物信息和养护记录
  • 删除权：您可以删除单条或全部数据记录，也可要求我们删除服务器端的数据
  • 注销权：您可以在应用内申请注销账号，注销后我们将在 30 个工作日内删除您的所有个人数据

7.1 撤回同意的方式

您可以通过以下方式撤回对个人信息收集的同意：

权限/功能 撤回方式
位置信息 设置 → 权限管理 → 关闭位置权限
相册/存储权限 设置 → 权限管理 → 关闭存储/相册权限
通知权限 设置 → 权限管理 → 关闭通知权限
云同步 应用设置 → 账号 → 选择本地存储模式
撤销全部授权 注销账号或卸载应用

说明：撤回同意后，我们将停止收集相应信息，但撤回前已收集的数据将按照本政策规定继续处理。撤回同意不影响撤回前基于同意进行的数据处理的合法性。

八、权限说明

本应用在运行过程中可能申请以下系统权限：

权限名称 用途说明 是否必须
存储/相册 读取和保存植物照片，用于生长记录和对比 是（拍照记录功能需要）
网络 数据云同步、天气数据获取、百科信息加载 是（基础功能需要）
通知 发送浇水、施肥等养护提醒通知 否（提醒功能需要，拒绝不影响其他功能）

提示：存储/相册和网络权限为基础功能所需，其余权限均为非必须权限，拒绝授权不影响本应用基础功能（植物管理、手动提醒等）的正常使用。您可以随时在系统设置中管理相关权限。

九、未成年人保护

本应用主要面向年满 18 周岁的成年人。如果您是未满 18 周岁的未成年人，请在监护人指导下使用本应用，并确保监护人已阅读并同意本隐私政策。我们不会主动识别未成年人的身份，但建议监护人关注未成年人的应用使用情况。

十、政策更新

我们可能会不时修订本隐私政策。更新后的政策将在应用内显著位置公布，并注明最新修订日期。如您在本政策更新后继续使用本应用，即视为您已阅读并接受修订后的政策。重大变更我们将通过应用内通知或弹窗方式提醒您。

  • 我们不会因您不同意提供非必要个人信息而拒绝为您提供基本功能服务
  • 我们将每 12 个月对数据收集清单进行审视和更新，确保数据收集的合理性和必要性
  • 中国大陆用户的个人数据原则上存储在中国大陆境内，特殊情况下的跨境处理将严格遵守相关法律法规
