CampReady 隐私政策

版本日期：2026年4月

一、引言

欢迎您使用 CampReady 露营装备清单（以下简称"本应用"）。本应用是一款面向露营爱好者的综合工具，提供装备清单管理、装备库浏览、重量统计、清单分享及智能推荐等功能。我们高度重视您的个人信息和隐私保护。本政策将帮助您了解我们如何收集、使用、存储和保护您的个人信息。请您在使用本应用前仔细阅读并理解本政策。

二、法律依据与规范

本隐私政策依据以下中华人民共和国法律法规及规范性文件制定：

  • 《中华人民共和国个人信息保护法》
  • 《中华人民共和国网络安全法》
  • 《移动互联网应用程序个人信息保护管理暂行规定》
  • 《关于规范移动互联网应用个人信息收集使用的通知》

我们承诺在个人信息处理活动中严格遵循"合法、正当、必要"原则，仅在具有明确、合理目的的情况下收集和处理您的个人信息，并采取对个人权益影响最小的方式进行处理。

三、信息收集与使用

为向您提供本应用的核心功能，我们可能收集以下个人信息：

信息类型 用途说明 收集方式 必要性
位置信息 用于获取当地天气信息以智能推荐装备、根据露营地点提供装备建议 用户授予位置权限后实时获取，可随时在系统设置中关闭 智能推荐功能必需
照片数据 用于装备拍照记录、露营行程照片记录，丰富您的露营日志 用户主动拍摄或从相册选取上传 可选功能

装备数据 记录用户的装备信息，包括名称、品牌、重量、分类等 用户主动录入 核心功能必需
清单数据 管理用户创建的露营装备清单，包括清单名称、装备列表及行程计划 用户主动录入 核心功能必需

四、数据存储与安全

我们采取多重措施保障您的数据安全：

  • Cloud DB 加密：同步至华为 Cloud DB 的数据（装备清单、行程记录等）均采用加密传输和加密存储，确保云端数据安全
  • Cloud Storage 云端加密：上传至华为 Cloud Storage 的照片文件采用服务端加密存储，传输过程使用 TLS/SSL 加密
  • 本地缓存：应用在设备本地缓存部分数据以提升使用体验，本地敏感数据采用 AES-256 加密存储
  • 数据最小化：我们仅收集实现功能所必需的最少数据，并在达到目的后及时删除或匿名化
  • 访问控制：采取严格的访问控制和日志审计措施，防止数据泄露、篡改或丢失

4.1 数据保留期限

数据类型 保留期限
装备清单、行程记录 用户主动删除或注销账号前持续保存；注销后 30 个工作日内删除
照片文件 用户可随时删除；删除后 Cloud Storage 同步清空
登录日志、访问日志 90 天后自动删除
设备信息、日志信息 30 天后自动删除或匿名化处理

4.2 数据跨境处理

本应用使用华为 Cloud DB 及 Cloud Storage 服务进行云端数据存储。相关服务器部署在中国大陆及中国香港等区域。

  • 所有数据传输均采用 TLS 1.2+ 协议加密，确保传输过程的安全性
  • 用户启用云同步功能即视为知悉并同意相关数据的跨境处理
  • 您可以随时在应用设置中禁用云同步，选择本地存储模式以停止数据跨境传输
  • 中国大陆用户的数据原则上存储在中国大陆境内

六、数据共享

重要声明：我们不会出售、出租或以其他商业方式向第三方提供您的个人数据。除以下情形外，我们不会向任何第三方共享您的个人信息：
  • 获得您的明确授权同意
  • 根据法律法规、诉讼争议解决需要，或行政、司法机关依法提出的要求
  • 为实现本政策所述功能，与上述第三方服务提供方共享必要信息

七、用户权利

根据相关法律法规，您对自己的个人信息享有以下权利：

  • 查看权：您可以随时在应用内查看您的装备清单、行程记录等个人信息
  • 导出权：您有权导出您的个人数据副本，包括装备清单、行程记录及统计数据
  • 删除权：您可以删除单条或全部数据记录，也可要求我们删除服务器端的数据
  • 注销权：您可以在应用内申请注销账号，注销后我们将在 30 个工作日内删除您的所有个人数据

7.1 撤回同意的方式

您可以通过以下方式撤回对个人信息收集的同意：

权限/功能 撤回方式
位置信息 设置 → 权限管理 → 关闭位置权限
摄像头权限 设置 → 权限管理 → 关闭相机权限
相册/文件存储权限 设置 → 权限管理 → 关闭相册/存储权限
云同步 应用设置 → 账号 → 选择本地存储模式
撤销全部授权 注销账号或卸载应用

说明：撤回同意后，我们将停止收集相应信息，但撤回前已收集的数据将按照本政策规定继续处理。撤回同意不影响撤回前基于同意进行的数据处理的合法性。

行使上述权利，请通过本政策末尾的联系方式与我们取得联系。

九、未成年人保护

本应用主要面向年满 18 周岁的成年人。如果您是未满 18 周岁的未成年人，请在监护人指导下使用本应用，并确保监护人已阅读并同意本隐私政策。我们不会主动识别未成年人的身份，但建议监护人关注未成年人的应用使用情况。露营活动涉及户外安全，未成年人须在成年人陪同下进行。
